Get startedIntroduction

Check your installation#

The self-test answers one question: does BRAIN, on this machine, recover the right answer? It writes mock spectra and a mock datacube whose true properties are known, fits them, and compares every recovered quantity with the truth.

Run it#

brainsp selftest --quick             # about a minute
brainsp selftest                     # everything, a few minutes
brainsp selftest --quick --device gpu

import brainsp

report = brainsp.selftest(quick=True)
report.passed          # True when every check passed

A run that passes ends with

======================================================================
  ALL 50 CHECKS PASSED in 103 s. BRAIN is working.
======================================================================

and the command exits with status 0. A run that fails lists each failed check with what it found and what it expected, keeps the mock data and the fits in the folder it names, and exits with a non-zero status. An installation script can therefore stop on a broken install:

pip install git+https://github.com/sureshparekh/brainv1 && brainsp selftest --quick

What it checks#

The checks run in this order, and each is printed as it finishes:

  1. The environment. Python, JAX and the device JAX runs on, and every other dependency. On a GPU, a double-precision product is computed on the card and checked, since JAX can list a card it cannot compute on.

  2. The template libraries. BasesGM, M13 with its own AGN set, and the seven AGN continua are installed, and their catalogues can be read.

  3. The mock data. Five spectra and a 16 × 16 datacube are written (see Mock data).

  4. The spectra. Each is fitted, and its stellar velocity, dispersion, extinction and light-weighted mean age are compared with the truth; for the AGN mock, the AGN light fraction as well; for the emission-line mocks, the gas velocity and the H\(\alpha\) flux. The observed-frame mock must give the same answer as its rest-frame twin once BRAIN has removed the redshift and the Milky Way’s dust.

  5. The datacube. It goes through the whole pipeline (signal-to-noise masks, the fit, the megacube). The number of spaxels fitted must match the S/N mask, and the velocity, dispersion and extinction maps must match the maps the cube was built from.

  6. The outputs. A map and the population figures are drawn, maps are exported as PNG and FITS, and the run is written as a Python file that then validates.

Each comparison has a tolerance of a few times the scatter measured on these mocks, and the tolerance is printed beside the result:

Options#

Option

Python keyword

What it does

--quick

quick=True

two spectra (the old population and the star-forming one) and only the cube’s spaxels with S/N > 20, fitted in spop

--device cpu|gpu|auto

device="gpu"

where to fit

--keep FOLDER

keep="FOLDER"

write the mock data and every fit to FOLDER, and keep them

From Python, brainsp.selftest() takes the same options as keywords and returns a report, whose passed is True when every check passed; each check is printed as it runs.
