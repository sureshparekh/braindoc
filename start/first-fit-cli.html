Get startedYour first fit

Your first fit from a terminal#

The brainsp command does everything the interface and the library do, without a display: on a laptop, on a remote server or in a cluster job. Each task is a sub-command; brainsp --help lists them and brainsp COMMAND --help describes one.

Some data#

brainsp examples                 # writes ~/.brainsp/examples
cd ~/.brainsp/examples

Fit a spectrum#

brainsp fit spectra/mock_old_population.spec

BRAIN prints its progress and, at the end, a one-line summary of each fit. The output folder, brain_out unless -o names another, now holds:

brain_out/
├── mock_old_population_summary.txt     every fitted and derived quantity
├── mock_old_population_fitted.txt      the observed and model spectra
├── mock_old_population_settings.txt    every setting the fit used
└── mock_old_population_fit.pdf         the standard figure

Change a setting#

Any setting can be given with --set NAME=VALUE, as many times as needed. The value is read as YAML, so lists and numbers need no quoting beyond what the shell needs:

brainsp fit spectra/mock_star_forming_lines.spec \
    --set nebular_mode=espop --set wavelength_scale=vacuum \
    --set "dust_range=[-1, 3]"

brainsp settings NAME prints what a setting does, and brainsp settings lists every one.

Keep the settings in a file#

For more than a few settings, write them to a file once and reuse it:

brainsp init settings.yaml               # every setting, with its documentation
nano settings.yaml                       # edit what you need
brainsp check settings.yaml              # validate, fit nothing
brainsp fit spectra/*.spec --settings settings.yaml -o results

brainsp check reports every problem it finds at once, with the reason and the fix, before any time is spent fitting.

Fit many spectra#

brainsp fit spectra/*.spec --corrections spectra/corrections.csv -o results

Spectra that share their settings, wavelengths and usable pixels are fitted together; the rest are fitted one at a time, spread over the CPU cores when there is no GPU. The corrections table gives each spectrum its own redshift and Galactic reddening (Corrections before the fit).

Fit a datacube#

brainsp cube cube/mock_cube.fits --redshift 0.02 \
    --wavelength-scale vacuum --sn 3 10 --fit-sn 3 \
    --set nebular_mode=espop -o cube_out

This computes the signal-to-noise masks at 3 and 10, fits the spaxels above 3 and writes cube_out/mock_cube-BRAIN_MEGACUBE.fits. Add --check to validate the run without fitting, --no-fit to run only the pre-fitting stages, or --export run_cube.py to write the run as a Python file instead.

Draw the results#

brainsp plot brain_out/mock_old_population_summary.txt -o fit.png
brainsp plot cube_out/mock_cube-BRAIN_MEGACUBE.fits                  # list the maps
brainsp plot cube_out/mock_cube-BRAIN_MEGACUBE.fits --map vrot_star -o v.png
brainsp plot cube_out/mock_cube-BRAIN_MEGACUBE.fits --diagnostic "BPT [N II]" -o bpt.png

The command line describes every command and option, and Command line prints each command’s own help.
