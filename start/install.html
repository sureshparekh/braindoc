Installation#

BRAIN is the Python package brainsp. A single pip command installs it, with the desktop interface and every library it needs; a second one adds GPU support.

Before you start#

You need Python 3.10, 3.11 or 3.12. Check which one you have:

python --version

We recommend installing BRAIN into an environment of its own, so that its versions of JAX and Qt never meet those of another project. With conda:

conda create -n brain python=3.12
conda activate brain

or, with the Python you already have:

python -m venv brain
source brain/bin/activate          # on Windows: brain\Scripts\activate

Install BRAIN#

pip install git+https://github.com/sureshparekh/brainv1

pip reads BRAIN’s requirements and installs them first:

Package

What BRAIN uses it for

jax (0.4.30 or newer)

the fit itself, compiled, on the CPU or a GPU

numpy, scipy

arrays and numerics

astropy

FITS files: datacubes and megacubes

matplotlib

every figure

PyYAML

settings files

PySide6 (6.5 or newer)

the desktop interface

The template libraries BasesGM, M13 and BC03 and the seven AGN continuum templates come inside the package, so nothing has to be downloaded separately.

Note

While the code repository is private, pip needs your GitHub access. With an SSH key on your GitHub account, use

pip install git+ssh://git@github.com/sureshparekh/brainv1.git

Over HTTPS, pip asks for your GitHub user name and a personal access token, not your password.

Add GPU support (optional)#

The default jax runs on the CPU, which is enough for spectra and for small datacubes. For an NVIDIA GPU on Linux, install the CUDA build as well:

pip install "brainsp[cuda] @ git+https://github.com/sureshparekh/brainv1"

This adds jax[cuda12] 0.6 or newer, which bundles the CUDA 12 libraries: no CUDA toolkit has to be installed on the system, only a recent NVIDIA driver (nvidia-smi prints its version). JAX 0.6 is the first release built with CUDA 12.8, which the RTX 50-series (Blackwell) cards need.

Check that BRAIN computes on the card, not only that JAX can see it:

brainsp selftest --quick --device gpu

The first lines of the report name the card and confirm a double-precision product computed on it:

[PASS] GPU computes   NVIDIA GeForce RTX 3060, compute capability 8.6: float64 product correct

A card newer than the installed JAX is listed by JAX and then fails at its first kernel; the self-test reports this, and pip install -U "jax[cuda12]" fixes it.

Tip

BRAIN computes in double precision throughout. Consumer GeForce cards run double precision at 1/32 or 1/64 of their single-precision speed, while data-centre cards (A100, H100) run it at half speed, so the second kind gains far more. CPUs and GPUs explains how BRAIN uses either.

Check the installation#

brainsp selftest --quick      # about a minute

The self-test writes mock data whose right answers are known, fits them, and checks every recovered quantity against the truth; Check your installation describes it. pip cannot run a program at the end of an installation, so run it once yourself.

Open the interface#

brainsp gui                   # or: brainsp-gui

To start BRAIN from the applications menu of your desktop instead, add it once:

brainsp desktop               # add BRAIN to the applications menu
brainsp desktop --remove      # and remove it again

On Linux this writes a .desktop file to ~/.local/share/applications, on macOS an application bundle in ~/Applications, and on Windows a Start Menu shortcut (which needs pip install pywin32).

What is installed where#

What

Where

the package

wherever pip installs packages; python -c "import brainsp; print(brainsp.__file__)" prints it

the commands

brainsp (everything) and brainsp-gui (the interface)

the template libraries

inside the package: brainsp/data/libraries/

libraries you add, examples, caches

~/.brainsp/ (set BRAINSP_HOME to move it)

compiled-code cache

~/.cache/brain/ (set BRAIN_CACHE_DIR to move it)

results

where you ask; ./brain_out (spectra) and ./brain_ifu_out (datacubes) by default

Install for development#

To work on BRAIN itself, install a clone in editable mode, so that a change to the code is live without reinstalling:

git clone https://github.com/sureshparekh/brainv1
cd brainv1
pip install -e ".[test,docs]"
pytest                          # the test suite, a few minutes
documentation/build.sh          # this website, into documentation/build/html

Update or remove#

pip install --upgrade git+https://github.com/sureshparekh/brainv1
pip uninstall brainsp

Uninstalling leaves ~/.brainsp (libraries you added, the examples, the template cache) and ~/.cache/brain (compiled code); delete them by hand if you want them gone. brainsp clear-cache empties only the caches.

If something goes wrong#

No module named brainsp. pip installed into a different environment from the one running Python. python -m pip install ... installs into exactly the Python you then run.

Could not load the Qt platform plugin "xcb" (Linux). Qt needs two system libraries to draw windows: sudo apt install libxcb-cursor0 libxkbcommon-x11-0 on Debian and Ubuntu. The fit does not need them; on a server without a display, use Python or the command line.

JAX finds no GPU. The CUDA build is not installed (pip install "jax[cuda12]"), or the NVIDIA driver is older than the CUDA 12 runtime needs.

The GPU is found but the first fit fails on it (no kernel image, an unsupported architecture). The card is newer than the installed JAX, as an RTX 50-series card is for JAX before 0.6: pip install -U "jax[cuda12]".

The first fit is slow. JAX compiles the fit the first time it meets a problem of a given size, which takes seconds to a minute. The compiled code is kept on disk, and every later run loads it in about half a second. Troubleshooting covers the rest.
