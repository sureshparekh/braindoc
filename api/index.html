API reference#

The public interface is everything importable from brainsp itself and the modules listed under Public modules; it is what the documentation and tutorials use and what is kept stable. The Developer reference documents every module underneath, for anyone changing BRAIN.

Fitting#

fit_spectrum

Fit one spectrum.

fit_spectra

Fit several spectra, each with its own pre-fit corrections if given.

fit_cube

Fit one datacube and open the megacube it produces.

CubePipeline

A datacube run: the preparation stages, the fit, and its outputs.

set_device

Choose the processor BRAIN fits on, before the first fit.

Settings#

Settings

Every BRAIN setting, with its default, as a dictionary.

Results#

FitResult

The result of fitting one spectrum, read from the files BRAIN wrote.

read_result

Read a fit already on disk.

read_megacube

Open a megacube BRAIN wrote.

read_corrections_table

Per-spectrum pre-fit corrections from a CSV file.

Masks#

read_mask

The regions of a wavelength mask file, as [(start, end, weight, label)].

write_mask

Write regions as a .sm mask file: the count, then one per line.

Runs as scripts, the self-test#

write_script

Write a run as one Python file.

selftest.run

Run the self-test.

Public modules#

plots

Figures from code: every plot the desktop interface draws, written to a file.

megacube

Reading a BRAIN megacube, and the emission-line diagnostics drawn from it.

mock

Mock spectra and a mock datacube whose right answer is known.

libraries

Template libraries: where they are, what is in them, how to add one.

scripts

Runs written out as one Python file each.

selftest([quick, device, folder, keep, verbose])

Run the self-test.

cli

The brainsp command.

corrections

BRAIN: corrections applied to a spectrum before it is fitted.

reddening_laws

Developer reference#

The modules BRAIN is built from. Their docstrings explain not only what each function does but why, including the defects each one was written to fix.

api

The brainsp scripting interface: everything the desktop interface does, from Python.

brainv1

NewBrain — Next-Generation Stellar Population Fitting Code

config

NewBrain Configuration Module All parameters in a single dataclass for clean management.

brain_settings

BRAIN — reads brain_setup.yaml and turns it into a validated fit configuration.

optimizer

NewBrain Optimizer Module — 100% JAX Backend Direct Pixel-Fitting via grid-search initialization + Levenberg-Marquardt.

fast_engine

NewBrain Fast Engine — unified 100% JAX forward model for all three photoionization modes.

solver

NewBrain Solver Module — JAX Backend Bounded Variable Least Squares (BVLS) with Tikhonov regularization.

spectral_engine

NewBrain Spectral Engine — JAX Backend Core computational routines: log-rebinning, Fourier broadening, dust attenuation.

errors

NewBrain Error Estimation Module — JAX Backend Monte Carlo bootstrap resampling for weight uncertainties.

emission_lines

Tied doublets, kinematic groups, and the Gaussian design matrix, with per-group velocity and dispersion for the joint fit.

line_catalogue

BRAIN: which emission lines exist, where they are, and on which wavelength scale.

atomic_data

BRAIN-v1 Atomic Data Module Reference tables for nebular physics: recombination coefficients, Balmer line ratios, Q(H) lookup tables, metal line calibrations.

nebular

BRAIN-v1 Nebular Physics Module Photoionization-based nebular continuum and emission line predictions.

gas_diagnostics

BRAIN — nebular diagnostics measured from the fitted emission lines.

instrumental_lsf

BRAIN — instrumental resolution and the line-spread function.

reddening_catalogue

BRAIN: which extinction curves exist, and what dust each one describes.

io_utils

NewBrain I/O Utilities Loading spectra, SSP libraries, masks, and writing output.

plot_fit

Plot NewBrain spectral fit results.

brain_cache

BRAIN caching layer — pay each fixed cost once, ever.

run_brain

BRAIN — run it.

fit_megacube_jax

BRAIN v1 — Pure JAX Datacube Fitter Fits all valid spaxels using jax.vmap batches.

fast_cube

A faster batch fitter for datacubes, kept apart from the one in use.

fit_datacube

Parallel Datacube Fitter for NewBrain Fits an entire MEGACUBE or FITS datacube in parallel.

cube_worker

One CPU worker of a datacube fit: python -m brainsp.cube_worker JOB.

spectra_worker

One CPU worker of a batch of spectra: python -m brainsp.spectra_worker JOB.

brain_ifu

BRAIN — the IFU runner.

ifu_modules

Pre-pass processing modules for BRAIN's IFU mode.

ifu_output

BRAIN — the megacube's extensions, and the compatibility contract.

line_products

BRAIN: per-line emission products for a datacube, in the megacube layout.

ifu_script_export

A configured datacube pipeline, written out as one Python file.

spectrum_script_export

A configured single-spectrum fit, written out as one Python file.

benchmark

BRAIN — timing benchmark.

install_desktop

brain_child

BRAIN, one fit, in a process of its own.

brain_subprocess

BRAIN, the interface's end of a fit that runs somewhere else.

brain_gui

BRAIN — desktop interface.

brain_ifu_gui

BRAIN — the datacube page of the desktop interface.

ifu_viewer

BRAIN — the datacube viewer.

results_view

brain_shell

BRAIN GUI: the workspace shell.

brain_qwidgets

BRAIN GUI — custom Qt widgets.

brain_theme

BRAIN GUI — palette, typography and stylesheet.
