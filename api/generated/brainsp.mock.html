brainsp.mock#

Mock spectra and a mock datacube whose right answer is known.

Every mock is built from the shipped BasesGM templates by a forward model that is written out here in full, independently of the fitter:

  1. a population: light fractions \(x_j\) of chosen templates, each

template normalised to 1 at :math:`\lambda_0` = 5500 A;

  1. dust: the mixture is reddened by

:math:`10^{-0.4 A_V [q(\lambda) - q(\lambda_0)]}`, with
:math:`q = A_\lambda / A_V` from the chosen law, so the fractions stay
light fractions at :math:`\lambda_0`;

  1. kinematics: a Gaussian line-of-sight velocity distribution, mean

:math:`v_\star` and dispersion :math:`\sigma_\star`, applied on a
logarithmic wavelength grid;

  1. emission lines: Gaussians of flux \(F_i\), velocity

:math:`v_{gas}` and dispersion :math:`\sigma_{gas}`, at vacuum
wavelengths from BRAIN's line catalogue;

  1. redshift: wavelengths multiplied by \(1 + z\) (flux density not

rescaled, BRAIN's convention);

  1. Galactic reddening at the observed wavelengths, \(E(B-V)\) with

:math:`R_V = 3.1` and the CCM law;

  1. noise: Gaussian, with signal-to-noise sn per pixel at

:math:`\lambda_0`, scaled as the square root of the flux elsewhere.

The true values are written beside each file (<name>.truth.json, and a TRUTH FITS file for the cube), which is what brainsp.selftest compares BRAIN’s answers with. Everything is seeded, so the same call writes the same files on every machine.

Typical use:

import brainsp
folder = brainsp.mock.write_examples()          # ~/.brainsp/examples
r = brainsp.fit_spectrum(folder + "/spectra/mock_old_population.spec")
