brainsp.brain_ifu_gui#

BRAIN — the datacube page of the desktop interface.

One scrolling page of panels with a sidebar that jumps to each of them: targets and output, the input extensions, the optional pre-pass stages, and the fit. An optional stage is a checkable group box, and ticking it puts that stage into the chain; the chain itself is built by brain_ifu, not here, so the interface and the command line cannot drift apart.

There is no control on this page that does not drive something that runs. A capability BRAIN’s IFU mode does not have has no panel, because a panel that looks like a setting and changes nothing is worse than an absent feature: it produces a run the user believes was configured one way and was not.

Progress is a real fraction. The number of batches is known before the first one is launched, so the bar reports stages finished and batches finished rather than reporting that something, somewhere, is happening.

The per-batch convergence figure, and deliberately not the run’s total.

The fitter logs conv n/m twice over: once per batch, where it counts that batch, and once more in the closing Done: line, where it counts the whole run. The viewer accumulates what it is told, so a pattern that matched both would add the total to the sum of its own parts and report twice the work that was done, at the moment the run ends and the number is finally looked at. Anchoring on the Batch the line opens with is what keeps the account true; Done: is already carried by the run finishing.

Bases: ChildRun

The pipeline, in a process of its own, watched from a thread of its own.

It used to run in this thread, with JAX_PLATFORMS set just before it, which selected nothing: JAX fixes its backend the first time it is used in a process and the interface had used it long before any cube was fitted. The selector now reaches a fresh interpreter, whose environment names the platform before it starts and which refuses to fit on anything else.

Two things come with the process that the thread could not offer. Stop ends the run, because ending a process is something an operating system can do and interrupting a compiled kernel is not. And a fit that dies inside JAX now dies on its own, leaving the interface holding a message instead of going down with it.

Bases: QWidget

The age bins the population maps are summed into.

Every bin here becomes two planes of PoPBins – <name>_light and <name>_mass – and nothing else reads them, so the table is the whole of the feature: add a row and two maps appear in the output, remove one and they do not.

The default is the six bins Suresh’s own MaNGA megacubes carry, with their exact edges, so a BRAIN map and one of those can be compared without re-binning either. The convention is the published one: an age belongs to a bin when min < age <= max, and bins may leave gaps but may not overlap, since a template inside two bins is counted twice and every map still looks reasonable afterwards.

bins()[source]#

The table as the runner wants it, with unreadable cells left as text.

A cell that is not a number is passed through rather than dropped or silently replaced, so that validation refuses the run and names the bin, instead of the interface quietly fitting a different set of bins from the one on the screen.
