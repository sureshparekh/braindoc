brainsp.api#

The brainsp scripting interface: everything the desktop interface does, from Python.

The four things most people need:

import brainsp

# one spectrum
result = brainsp.fit_spectrum("galaxy.spec", nebular_mode="espop",
                              wavelength_scale="vacuum")
print(result.v0, result.sigma, result.av, result.mean_log_age_light)

# many spectra, each with its own redshift and Galactic reddening
results = brainsp.fit_spectra("spectra/*.spec",
                              corrections="corrections.csv")

# a datacube
cube = brainsp.fit_cube("manga-8626-12704-LOGCUBE.fits", redshift=0.04724,
                        sn_mask=[3, 5], fit_sn_threshold=3)
velocity = cube.plane("vrot_star")

# a datacube pipeline, every stage spelled out
pipeline = brainsp.CubePipeline(cubes=[...], redshift=..., ...)
pipeline.run()

Settings travel as a Settings object: a dictionary of every BRAIN setting with its default, which can be read from or written to a YAML file and whose keys are also attributes. Every function also accepts settings as keyword arguments, which override the Settings given.

JAX picks its device the first time it is used in a process, so the device has to be chosen before the first fit: pass device= to the first call, or call set_device() first. "auto" (the default) uses a GPU when JAX can see one.

class brainsp.api.Settings(source=None, **overrides)[source]#

Bases: dict

Every BRAIN setting, with its default, as a dictionary.

Keys are also attributes, so s.nebular_mode and s["nebular_mode"] are the same thing. An unknown key is refused, with the nearest valid name suggested, rather than silently ignored.

Parameters:
sourcestr, dict or Settings, optional

A settings file (.yaml), or a mapping of settings. Missing keys take their defaults.

**overrides

Settings to change, by name.

Examples

>>> import brainsp
>>> s = brainsp.Settings(nebular_mode="espop", wavelength_scale="vacuum")
>>> s.dust_range
[0.0, 5.0]
>>> s.ages = [1e8, 1e9, 1e10]
>>> s.changed()                       # what differs from the defaults
{'nebular_mode': 'espop', 'wavelength_scale': 'vacuum', 'ages': [...]}
>>> s.save("my_settings.yaml")
>>> brainsp.Settings("my_settings.yaml") == s
True
>>> print(brainsp.Settings.describe("dust_range"))

brainsp.api.fit_spectra(spectra, settings=None, *, corrections=None, output_dir=None, device=None, quiet=False, stop_on_error=False, workers=None, **overrides)[source]#

Fit several spectra, each with its own pre-fit corrections if given.

Templates and the compiled engine are loaded once and reused, so a batch costs far less than the same fits run one at a time.

Parameters:
spectrastr or list of str

Files, or a glob pattern such as "spectra/*.spec". May be omitted (None) when corrections is a table: its spectra are fitted.

settingsSettings, dict or str, optional

Settings shared by every spectrum.

correctionsstr or dict, optional

A CSV table (see read_corrections_table()) or a mapping {spectrum: {setting: value}} of per-spectrum settings, typically spectrum_redshift, spectrum_in_rest_frame, galactic_ebv, galactic_rv, galactic_law.

output_dir, device, quiet, **overrides

As for fit_spectrum().

stop_on_errorbool

Raise on the first failure. Otherwise a failed spectrum gives a result whose error_message says why, and the batch carries on.

workersint or “auto”, optional

On a CPU, fit the spectra on this many worker processes at once, each with one thread and each keeping its own compiled fit warm. "auto" (the default on a CPU) uses every core but one, as many as the free memory allows; 1 fits them all in this process. On a GPU the spectra are fitted one after another in this process, which keeps the device busy on its own.

Returns:
list of FitResult

In the order the spectra were given.

class brainsp.api.FitResult(summary_file, fitted_file=None, spectrum=None)[source]#

Bases: object

The result of fitting one spectrum, read from the files BRAIN wrote.

A fit writes two files: <name>_summary.txt (the fitted parameters, the population vector, the emission lines) and <name>_fitted.txt (the observed and model spectra, column by column). This object reads both.

Attributes:
spectrumstr

The input spectrum.

summary_file, fitted_filestr

The two output files.

valuesdict

Every value [label] line of the summary, by label, as text.

v0, sigmafloat

Stellar velocity and velocity dispersion in km/s (v0_min, vd_min; the dispersion is OBSERVED, including the instrument, unless instrumental_resolution was given; see sigma_star).

sigma_starfloat or None

The intrinsic stellar dispersion, when the instrumental resolution was known.

av, yavfloat

V-band extinction of the whole population and the extra extinction of the youngest components, in magnitudes.

chi2, chi2_data, adevfloat

Reduced chi-squared (with and without the penalty rows), and the mean absolute deviation in per cent.

populationsnumpy.ndarray

Structured array, one row per template: x (light fraction, per cent, at the normalisation wavelength), mini and mcor (initial and present mass fractions, per cent), age (yr), Z, mstars, name, stellar (False for an AGN component).

linesdict

Emission-line fluxes and errors, {name: (flux, error)}, in the units of the input spectrum times Angstrom; empty in spop. Names are BRAIN’s ("Halpha_6563", "[S II]_6716" …). The tied doublets appear as "[O III]_Doublet" and "[N II]_Doublet" (the strong line’s flux) and also under each member’s own name, at the fixed ratio.

wavelength, observed, model, stellar, emission, error, residualndarray

The columns of the fitted-spectrum file.

Examples

>>> r = brainsp.fit_spectrum("galaxy.spec")
>>> r.v0, r.sigma, r.av
(188.3, 47.55, 0.2171)
>>> r.mean_log_age_light, r.mean_log_age_mass
>>> young = r.populations[r.populations["age"] < 1e8]["x"].sum()
>>> r.plot("galaxy_fit.pdf")

brainsp.api.read_corrections_table(path)[source]#

Per-spectrum pre-fit corrections from a CSV file.

The same table the desktop interface loads: a header row, the spectrum’s file name in the first column, then any of redshift (or z), ebv, rv, law and rest_frame. A redshift in the table is one BRAIN removes (the spectrum is taken to be in the observed frame) unless rest_frame says otherwise. Empty cells keep the defaults.

Parameters:
pathstr

The CSV file. File names are relative to its folder.

Returns:
dict

{absolute spectrum path: {setting: value}}, ready for fit_spectra().

class brainsp.api.CubePipeline(cubes, redshift=None, settings=None, *, output_dir='brain_ifu_out', flux_hdu='FLUX', error_hdu='IVAR', error_type='inv_variance', mask_hdu='MASK', wavelength_scale=None, galactic_ebv=0.0, galactic_rv=3.1, galactic_law='CCM', spatial_binning=None, degrade_resolution=None, spectral_binning=None, butterworth=None, sn_mask=None, fit_sn_threshold=None, wavelength_mask=None, batch_size=None, population_bins=None, flxobs_step=None, sfr_bins=None, fc_bins=None, bb_bins=None, galaxy_distance=None, flux_scale=None, per_cube=None, overwrite=True, save_config=True, fit=True)[source]#

Bases: object

A datacube run: the preparation stages, the fit, and its outputs.

The stages run in this order, each only when asked for: Galactic dereddening, spatial binning, resolution degrading, spectral resampling, Butterworth filter, signal-to-noise mask, fit. The fit writes one megacube per cube, <cube>-BRAIN_MEGACUBE.fits.

Parameters:
cubesstr or list of str

Datacube FITS files (or a glob pattern).

redshiftfloat or None

The galaxy’s redshift; BRAIN divides each cube’s wavelengths by 1 + z. Required, unless every cube has one in per_cube; 0 for a cube already in the rest frame.

settingsSettings, dict or str, optional

The physics of the fit (templates, mode, dust, kinematics …), as for a spectrum. spectrum is ignored.

output_dirstr

Where megacubes are written.

flux_hdu, error_hdu, mask_hdustr

Names of the cube’s flux, uncertainty and bad-pixel extensions (MaNGA: FLUX, IVAR, MASK). mask_hdu may be None.

error_typestr

What error_hdu holds: "inv_variance", "variance", "error" or "inv_error".

wavelength_scale{“air”, “vacuum”}, optional

The cube’s wavelength scale. Required for espop, nepop and photopop (MaNGA and SDSS are vacuum; MUSE and CALIFA air).

galactic_ebv, galactic_rv, galactic_lawfloat, float, str

Milky Way reddening to remove before anything else; 0 turns the stage off.

spatial_binningint, optional

Bin spaxels n x n.

degrade_resolutiondict, optional

{"input type": "R", "input value": 2200, "output type": "R", "output value": 1000}; resolutions as R, FWHM or sigma (Angstrom).

spectral_binningfloat, optional

Resample the wavelength axis by this factor.

butterworthdict or bool, optional

Spatial low-pass filter; True for the defaults or {"order": 3, "range": 0.3}.

sn_masklist of float or dict, optional

Signal-to-noise thresholds to compute masks for (e.g. [1, 3, 5, 10]), or {"thresholds": [...], "sn window": [4000, 6000], "method": "ivar"}.

fit_sn_thresholdfloat, optional

Fit only the spaxels with S/N above this threshold (one of the sn_mask thresholds).

wavelength_maskstr or list, optional

A mask file (.sm, .gm or a list of start end [weight]), or regions [(start, end, weight), ...]; applied to every spaxel.

batch_sizeint, optional

Spaxels fitted at once (automatic by default).

population_binslist, optional

[(name, youngest_yr, oldest_yr), ...] for the PoPBins maps (min exclusive, max inclusive). Bins may overlap, so a total such as ("xy_Tot", 10, 2e8) is a bin of its own.

sfr_binslist, optional

[(name, min_yr, max_yr), ...]: star-formation-rate maps, the mass formed in the bin over its width, Msun/yr. Need galaxy_distance.

fc_bins, bb_binslist, optional

[(name, min, max), ...]: the light (per cent) of the featureless power laws with min < exponent <= max, or blackbodies with min < temperature (K) <= max, e.g. [("FC_Tot", 0.245, 0.75)], [("BB_warm", 699, 1000)].

galaxy_distancefloat, optional

Distance in Mpc; with it the megacube carries Mstar and Mpcross (Msun) and the SFR maps. Per cube: a galaxy distance column of per_cube.

flux_scalefloat, optional

The number the cube’s flux unit carries (1e-17 for MaNGA); read from BUNIT when not given.

per_cubestr or list of dict, optional

Per-cube overrides: a CSV file (first column the cube, then any of redshift, ebv, rv, law, mask file, …) or a list of {"target": path, "redshift": ...}.

overwritebool

Re-run a cube whose megacube exists.

fitbool

Run the fit (False runs the preparation stages only).

Examples

>>> import brainsp
>>> p = brainsp.CubePipeline(
...     "manga-8626-12704-LOGCUBE.fits", redshift=0.04724,
...     settings=brainsp.Settings(nebular_mode="espop"),
...     wavelength_scale="vacuum", sn_mask=[3, 5], fit_sn_threshold=3,
...     wavelength_mask="emission_lines.sm")
>>> p.validate()
>>> outputs = p.run(device="gpu")
>>> p.export_script("run_8626.py")    # the same run, as one Python file
classmethod from_config(cfg, settings=None)[source]#

A pipeline from the dictionary BRAIN’s datacube runner reads (what the desktop interface builds, or brain_ifu.load_config reads).

The fit’s settings come from the file cfg names unless settings is given; a wavelength-mask file is read into regions, so the pipeline no longer depends on it.

config()[source]#

The pipeline as the dictionary BRAIN’s datacube runner reads.

Writes the fit’s settings, and a wavelength mask given as regions, into the output folder, because the runner reads both from files; the megacube then records exactly what it was fitted with.
