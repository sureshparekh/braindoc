brainsp.ifu_modules#

Pre-pass processing modules for BRAIN’s IFU mode.

A module declares its own default configuration, is handed the open HDU list of one datacube, and returns the HDUs it produced. The runner appends them to that same list, so the list accumulates into a megacube. Configuration layers module defaults, then the constructor keywords, then the per-target overrides a targets CSV supplies, and a key that was never declared as a default is ignored rather than silently creating a setting nothing reads.

The output extension names are those of the MaNGA megacubes of Riffel et al. (2023, MNRAS 524, 5640), so that tooling written against those megacubes reads a BRAIN megacube unchanged. Three choices are deliberate: dereddening uses BRAIN’s own twelve-curve registry in reddening_laws.py and applies the extinction the user asked for rather than a curve’s internal R_V; the signal-to-noise map is the mean per-pixel signal-to-noise, which is dimensionally a ratio; and the wavelength axis is read from a WAVE extension when one is present, because reconstructing it linearly from CD3_3 is wrong on any cube whose third axis is not linear.

Degrading the resolution of the data is provided and warns every time it runs.

class brainsp.ifu_modules.IFUModule(**kwargs)[source]#

Bases: object

Base class for a pre-pass module.

Subclasses set name, fill self.default_parameters inside _set_default_parameters, and implement execute. progress_hook is set by the runner to a callable taking a fraction and a message; modules that take a noticeable time call it, and the default does nothing so a module can always call it.

spaxel_hook is the same idea one level finer: a stage that works through a cube spaxel by spaxel calls it with the flat indices it has just finished and the spatial shape those indices address, so that an interface can show the field filling in rather than a bar advancing. Only the fit has anything to say through it, and nothing in the pipeline depends on anybody listening.

brainsp.ifu_modules.wavelength_axis(hdu_list, ext_name)[source]#

The wavelength of every plane of an extension, in Angstrom.

A WAVE extension of the right length is believed in preference to the world coordinate system, because it is the only description that is right whatever the sampling. Reconstructing the axis as CRVAL3 + k * CD3_3 is correct only for a linearly sampled cube, and a MaNGA LOGCUBE is not one: the reconstruction ends roughly 1000 A short at the red end, which quietly drags H-alpha and the red sky forest into a window the user asked to be continuum.

Without a WAVE extension the axis is built from the header. CTYPE3 decides how: a name ending in -LOG is logarithmic, and the two conventions in circulation are told apart by the size of CRVAL3 – a reference wavelength in Angstrom for the FITS form, a base-ten logarithm for the IRAF form.

brainsp.ifu_modules.to_sigma_like(data, data_type)[source]#

Map any of the six data types onto the quantity that combines linearly.

A flux adds like a flux and a one-sigma error adds like a flux; an inverse variance does not. Every module that averages, sums or convolves planes therefore converts to flux or to sigma first, combines, and converts back. Non-finite values survive the round trip as NaN so that the combination step can decide what to do with them, rather than having them turn into zeros here where nothing can tell them from real zeros.

brainsp.ifu_modules.from_sigma_like(data, data_type)[source]#

The inverse of to_sigma_like.

An inverse-variance or inverse-error plane that comes back non-finite is written as zero, because zero is what an inverse variance means when there is no information at that pixel, and it is what MaNGA already writes there. A flux-like plane keeps its NaN, because there zero is a measurement.

brainsp.ifu_modules.inverse_variance(data, data_type)[source]#

A statistical plane expressed as the inverse variance the fit weights with.

A cube may declare its uncertainty as an error, a variance or an inverse variance, and MUSE ships a variance plane where MaNGA ships an inverse variance, so a fitter that reads only one of them cannot fit half the instruments in use. The conversion is done once, here, on the way into the fit, so nothing downstream has to know which kind the file held.

An inverse variance is returned untouched rather than round-tripped through sigma: the round trip is not the identity in floating point, and the weights the fit uses must be the numbers the file holds. For the other kinds a pixel that comes out non-finite is given zero, which is what an inverse variance means where there is no information and what MaNGA already writes there; the fit drops those pixels either way.

‘flux’ and ‘inv_flux’ are not uncertainties and are refused rather than quietly interpreted as one.

brainsp.ifu_modules.require_extension(hdu_list, ext_name, what)[source]#

The named extension, or an error naming what is actually in the file.

A missing extension is the failure this pipeline makes easiest to reach: stages rename what they produce, so one wrong name in a targets CSV column surfaces as a KeyError from astropy several stages later with nothing in it to say which stage asked or what it could have asked for instead.

class brainsp.ifu_modules.Dereddening(**kwargs)[source]#

Bases: IFUModule

Foreground extinction removed from the flux cube. Writes FLUX_DRD.

The curve comes from BRAIN’s own registry, so all twelve laws the fitter can use are available here too, and the one used is named in DRD_LAW beside DRD_EBV and DRD_RV. Every curve in that registry is k(lambda) = A_lambda / A_V, so the correction is 10 ** (0.4 * A_V * k), with A_V = R_V * E(B-V) taken from the settings given rather than from a value buried in the curve: a run that writes R_V = 3.1 into its header has had R_V = 3.1 applied to it.

The starburst curves CAL, CCC and HZ5 were derived with R_V = 4.05 and that is the value to pair them with; the module does not impose it, because silently overriding the user’s R_V while still recording it is exactly the trap this note exists to avoid.

Configuration: hdu flux (FLUX), ebv (0.0), rv (3.1), law (CCM).

The curve is the only thing in this file that is evaluated in JAX, so it and the double-precision switch it needs are imported here rather than at the top of the module. Every other stage is numpy and scipy, and a module list that started a JAX backend merely by being described would put one in the interface process, where the device has not been chosen yet.

class brainsp.ifu_modules.ButterworthFilter(**kwargs)[source]#

Bases: IFUModule

A low-pass Butterworth filter over the two spatial axes. Writes FLUX_BW.

The transfer function is H = 1 - 1 / (1 + (range / r) ** (2 * order)) on the radius normalised to its largest value, with the zero frequency rolled to the corner to match the fast transform’s ordering. Pixels that are not finite are set to zero before the transform, because a single NaN propagates to the whole plane, and restored to NaN afterwards.

Configuration: hdu flux (FLUX), order (3), range (0.3).

This filter mixes neighbouring spaxels. Any chi-squared computed after it is assuming pixel noise that the filter has correlated, so it is logged as a warning every time it runs, like the resolution degrader.

It is spatial only: nothing is done along the wavelength axis. At the default order and range the kernel spreads one spaxel’s light over about six of its neighbours – a point source keeps roughly a sixth of its peak – and that width is set by range in spaxels, not by the size of the field. On a field only a few spaxels across it is therefore the whole field, and light that lands on a spaxel which was not finite is dropped rather than returned, so a small cutout can come out of here at a small fraction of the flux it went in with. The fraction that survived is measured, written to BW_KEPT and logged, because a stage that quietly scales the data is exactly the kind of thing this code exists to catch.

class brainsp.ifu_modules.SpectralResampler(**kwargs)[source]#

Bases: IFUModule

A cube put onto a uniform wavelength step. Writes <EXTNAME>_BIN.

The new grid runs from the first wavelength in steps of resample size Angstrom, and the header it carries describes that grid: CRPIX3 1, CRVAL3 the first wavelength, and the step in CDELT3 or CD3_3, whichever the input used. RSP_SIZE records the step.

Resampling is linear interpolation over the pixels that are finite, which is what it takes to reproduce an existing analysis. It is lossy and it is not what BRAIN’s fit does: the fit puts the flux onto its log grid with a flux-conserving integral, from whatever grid it is given. Run this stage when you are matching someone else’s processing, not to help the fit.

Configuration: hdu target (FLUX), data type (flux), resample size (1.0).

class brainsp.ifu_modules.SpatialResampler(**kwargs)[source]#

Bases: IFUModule

Square blocks of spaxels summed into one. Writes <EXTNAME>_RSP.

Each output spaxel is the sum over an N by N block, taken as a NaN- tolerant mean multiplied by N on each axis so that a block with missing spaxels is scaled up to a full block rather than being biased low. A block with no finite spaxel at all has nothing to scale up and stays NaN; the empty-slice warning numpy raises for it is expected and is silenced, since the NaN it returns is the right answer and carries the same information. Blocks that do not fit whole into the array are dropped, so the output is floor(n / N) on each axis.

A data-quality mask cannot be carried through this stage, since a flag is not an additive quantity; the runner drops the mask and says so rather than passing on one that no longer lines up.

Configuration: hdu target (FLUX), data type (flux), resample size (4).

class brainsp.ifu_modules.DegradeResolution(**kwargs)[source]#

Bases: IFUModule

The data convolved down to a coarser resolution. Writes <EXTNAME>_DEGR.

The kernel width is sqrt(sigma_out ** 2 - sigma_in ** 2), clipped at zero where the data is already coarser than the target, and truncated at twenty sigma. Resolutions are given as a resolving power R, a FWHM in Angstrom or a sigma in Angstrom; an R with a reference wavelength is a constant width rather than a constant resolving power.

This is not BRAIN’s route to matching a library to an instrument. BRAIN convolves the templates up to the data, which leaves the pixel noise uncorrelated; this smooths the data, which does not. It exists so that an existing analysis made that way can be reproduced, and it warns every time it runs. Asking for it and for instrumental_resolution at once is refused before the run starts, because that counts the instrument twice.

Configuration: hdu target (FLUX), data type (flux), input type (R), input value (2200), input ref wave (None), output type (R), output value (1000), output ref wave (None).

class brainsp.ifu_modules.SNMask(**kwargs)[source]#

Bases: IFUModule

Which spaxels carry enough signal to fit. Writes SN_MASKS_<threshold>.

One integer plane per threshold, 1 where the signal-to-noise in the window exceeds it, and the continuous map they were cut from as SNMAP, which costs nothing to keep and every user otherwise recomputes.

The default is the mean over the window of the per-pixel signal-to-noise, mean(flux * sqrt(ivar)). That is the standard definition, it is what the fitter sees pixel by pixel, and it degrades gracefully where the inverse variance is zero, which is how MaNGA marks an unusable pixel. A form that takes the square root a second time returns a quantity with units of the square root of a flux, which at a threshold of 10 selects zero of 2387 spaxels of a real MaNGA cube where this form selects 605. median(flux * sqrt(ivar)) is offered for windows with unavoidable sky residuals, and the mean of the ratio to an error or variance plane, and the flux mean over its standard deviation, for cubes that carry no error at all. SN_METH records which was used.

The window is rest-frame: the wavelength axis is divided by 1 + z before it is applied.

Configuration: hdu flux (FLUX), hdu ivar (IVAR), hdu var (VAR), hdu error (ERROR), sn window ([4000, 6000]), thresholds ([10]), redshift (0.0), method (ivar).
