brainsp.brainv1#

NewBrain — Next-Generation Stellar Population Fitting Code

Direct Pixel-Fitting spectral synthesis engine. Pure physical model: No multiplicative or additive polynomials. All core operations in Fourier/matrix space → GPU-ready.

Supports three photoionization modes:

"spop"       — Standard stellar-only fitting with empirical Gaussian emission lines.
"nepop" — Nebular continuum from Q(H) included; emission lines still empirical.
"photopop"      — Self-consistent: nebular continuum + predicted H lines from Q(H).

Main pipeline driver.

Author: Suresh Parekh

brainsp.brainv1.clip_outliers_and_refit(fitter, result, inv_sigma, flux_log, err_log, n_ssp, cfg)[source]#

Zero the weight of pixels the model cannot explain, and fit again.

A pass measures the deviation of every fitted pixel from the current model in units of its own error, zeroes the weight of everything beyond sigma_clip_threshold, and re-optimises from the parameters already reached. The re-fit is inside the loop on purpose: the criterion is a property of the residual, so a second pass that reuses the first pass’s residual can only find the pixels it has already removed and is a no-op. That is what the loop used to be. cfg.n_clip_iterations is therefore a count of clip-and-refit passes, and one pass – the default – is one clip and one re-fit.

The deviation is abs(resid) / err_log, the error of the pixel as the file reports it, not abs(resid) * inv_sigma. The two differ by the square root of the mask weight, and a mask weight is an instruction about how much a pixel should count, not a statement about how noisy it is; folding it in would make the threshold mean something different wherever a mask is loaded with a weight other than zero or one. Without errorbars there is no per-pixel scale and the residual’s own scatter stands in for one.

Returns the last result, the surviving weights, how many pixels went, and the time the re-fits took. Assigning to fitter.inv_sigma is what makes the re-fit see the clip; the property does the cache invalidation.
