Bases: object

Complete configuration for a NewBrain spectral fit.

Three fields describe line-spread functions rather than physics, and are worth a note here because getting them wrong is silent:

instrumental_resolution

The data's line-spread function, in the OBSERVED frame. A number is a
FWHM in Angstrom; a string may name a unit ("45 km/s"); a path names a
two-column file of wavelength and FWHM. None means BRAIN knows nothing
about it, applies no correction, and says so in the summary.

library_resolution

The template library's, at rest wavelengths. None means read it from
the template file headers, and report it as unknown if they are silent.

spectrum_redshift

The redshift that was removed from the spectrum before BRAIN saw it.
instrumental_resolution is evaluated at lambda_rest * (1 + z) because
the spectrograph saw the light there, while library_resolution is
evaluated at lambda_rest. A spectrum still in the observed frame takes
0.0.

wavelength_scale is a fourth field of that kind, and is silent in the same way. It is ‘air’ or ‘vacuum’ and it describes the OBSERVED spectrum, which is the scale the emission-line rest wavelengths are put on. None means it was never declared, which is refused before a fit that needs it rather than defaulted: the two scales differ by about 83 km/s, the difference is very nearly constant in velocity so it lands almost entirely on the fitted gas velocity, and chi2 moves by less than 0.05 per cent with random sign. A wrong answer here is invisible in the fit. It is not needed, and is not demanded, in ‘spop’, which builds no emission lines at all.

n_clip_iterations counts clip-and-refit passes, not passes over a residual that never changes: each pass zeroes the weight of the pixels beyond sigma_clip_threshold and then re-optimises, so the pass after it judges a different model. The default is one pass, which is one clip and one re-fit; 0 turns clipping off. Every pass costs a complete re-fit, on a spectrum and on every spaxel of a cube alike. sigma_clip_scale says what the threshold multiplies: ‘error’, each pixel’s own error (as STARLIGHT’s NSIGMA clipping), or ‘typical’, the larger of that and the spectrum’s typical residual.
