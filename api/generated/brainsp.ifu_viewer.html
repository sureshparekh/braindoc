brainsp.ifu_viewer#

BRAIN — the datacube viewer.

A map of the cube, and the spectrum of whichever spaxel is clicked on it.

Everything that touches the file happens on a worker thread and nothing is read that is not about to be drawn: a collapsed map is built from a few hundred wavelength planes rather than all of them, and a spectrum is one strided read. A 74x74x6732 cube opens and draws without the interface stopping, which is the whole point of the arrangement.

The map offers whatever the file actually holds. A plain datacube offers its flux collapsed over wavelength or over a band, and any two-dimensional extension of the right shape, which for MaNGA includes the broadband images. A megacube offers all of that plus every plane of PoPBins, addressed by its DATA<n> card exactly as the analysis tools address it, and the fit’s own maps. Nothing here is a hard-coded list of quantities, so a plane added to the output appears here with no change.

While a fit runs, the spaxels each batch finishes light up on a progress map as they complete. The animation is driven by a timer on the interface thread and the fitting thread only ever appends indices to an array, so drawing never holds the fit up.

Whatever SN_MASKS_<t> planes a file carries are offered as a cut, and the spaxels a chosen threshold throws away are drawn yellow over the map with the count of what survives next to the selector. Two formats write these planes with opposite polarity and neither says which it used, so the viewer works it out from the file and states what it decided.

Colour maps are perceptually uniform and the state of a spaxel is never carried by colour alone: what is not a converged fit is hatched as well as greyed, the yellow cut is cross-hatched, and the counts are written under the map.

brainsp.ifu_viewer.FLASH_SECONDS = 0.45#

How long a freshly fitted spaxel stays bright. A batch lands as a flash that decays over this time, then settles into the steady fill, so the eye can follow where the fit has just reached rather than only that the field is filling. Long enough to be seen, short enough that consecutive batches do not blur into one glow.

brainsp.ifu_viewer.orientation_text(header)[source]#

Which way round the map is drawn, read from the file rather than assumed.

The map is drawn with the array’s first row at the bottom, so a cube whose world coordinate system has right ascension decreasing with column and declination increasing with row is north-up and east-left as displayed. Any other arrangement is named instead of being quietly mislabelled, and a cube with no celestial coordinates is reported as having none.

brainsp.ifu_viewer.map_entries(hdu_list, flux_ext, shape)[source]#

Every map this file can draw, derived from the file and not from a list.

A three-dimensional extension carrying DATA<n>, PLANE<n> or PARAM<n> cards is a stack of named maps and is offered one plane at a time under the name its own card gives it, which is how the analysis tools address PoPBins. A two-dimensional extension of the cube’s spatial shape is one map. The flux cube itself is offered collapsed, since that is the image a cube is usually recognised by.

brainsp.ifu_viewer.sn_mask_planes(hdu_list, shape)[source]#

The SN_MASKS_<t> extensions a file actually carries, lowest threshold first, each as a boolean plane of where the value is non-zero.

Discovered from the file rather than from a list, because the ladder of thresholds is a choice whoever wrote the cube made: the published megacubes carry 1, 5, 10 and 20, a BRAIN chain carries whatever its thresholds setting said, and most cubes carry none at all. A name that does not end in a number, or a plane that is not on the cube’s spatial grid, is not one of these and is skipped.

brainsp.ifu_viewer.sn_mask_convention(planes, hdu_list=None, flux_ext=None)[source]#

Which value in an SN_MASKS_<t> plane means the spaxel was kept.

Two codes write these masks with opposite polarity and neither stamps a card that says so, so the viewer works it out from the file instead of assuming. Getting it backwards paints exactly the wrong spaxels, and it does so plausibly, which is why this is decided rather than guessed.

Three rules, in the order of how little they have to trust:

The kept set can only shrink as the threshold rises – a spaxel above S/N 20 is above S/N 10 – so with two or more thresholds present the value whose count falls monotonically is the kept one. This needs no header and no flux and it decides both conventions.

Failing that, a THRESH or SN_METH card is stamped by BRAIN’s own S/N stage, whose planes are 1 where the threshold was exceeded.

Failing that, the two groups are compared against a signal-to-noise measure: SNMAP when the file carries it, otherwise the median flux per spaxel sampled from the cube. The group with the higher median is the kept one.

Returns the keep value, whether anything actually decided it, and the sentence the interface shows. When nothing decides it the smaller group is called the kept one, which is the reading that overstates neither how much data survives nor how little, and the caller is told it is a guess.

brainsp.ifu_viewer.safe_name(text)[source]#

A plane’s name turned into one a file system will take, unambiguously.

Spaces and punctuation become single underscores and the result keeps its case, so PoPBins Mage_L becomes PoPBins_Mage_L and is still the name the file calls it. A name that collapses to nothing is given one, because an empty file name silently becomes a dot file.

brainsp.ifu_viewer.scaled(values, scale)[source]#

The limits and the array a map is drawn with, for one of the three scales.

The clipped linear scale is the default because a single bright spaxel otherwise takes the whole colour bar and the field goes flat. The full range is offered next to it so that what the clip hides is one click away, and neither is applied without the colour bar saying which.

Bases: QThread

Every read of a FITS file the viewer makes, on one thread of its own.

The interface posts a request and forgets about it; the answer arrives as a signal carrying the path it was computed from, so a result for a cube that has since been closed is recognised and dropped instead of being drawn over the new one. Only the newest request of each kind is kept: dragging across the map queues one spectrum, not two hundred.

The right-hand half of the datacube page: a map, and one spaxel’s spectrum.

Holds no configuration of its own. The extension it reads and the redshift it works in are the ones the pipeline on the left is set up with, so what is shown here is what the fit would see, and the two cannot describe different things.

closeEvent(event)[source]#

Stop the reading thread with the panel.

Also registered with atexit, because a Qt thread that is still running when its C++ object is destroyed aborts the process, and a script that builds this panel without ever running an event loop – which every test here does – never gets a close event. The abort came after everything had been written, so it looked like a crash at the end of a run that had in fact finished.

Show a cube, and the megacube beside it when one has been written.

The megacube is preferred when it exists, because it holds the cube it was fitted from as well as the fit, so nothing is lost by opening it and the maps and the model come with it. The toggle above the map says which of the two is open and switches between them.

begin_run(n_y, n_x, background=None)[source]#

Start the progress map: a field of the fit’s own shape, all unfitted.

The shape is the fit’s, not the file’s, because a spatial resampling stage in front of the fit changes it, and showing progress on the wrong grid would put a spaxel in the wrong place. The collapsed flux map is dimmed underneath it when the two shapes agree, and left out when they do not.

The denominator starts as the whole field, which is the only number known at this point, and is replaced by the count of fittable spaxels as soon as the fit reports one. Saying ‘of 5476’ while the fit will only ever attempt 1452 of them is a progress bar that stops at a quarter and looks broken.

mark_spaxels(indices)[source]#

note_valid(n_valid)[source]#

How many spaxels of the field the fit will attempt at all.

note_batch(converged, attempted)[source]#

How many of a finished batch converged, as against how many were tried.

The fit tells the interface which spaxels a batch touched and not which of them succeeded, so the lit field is an attempt count and is labelled as one. This is the only convergence figure available while a run is in flight, and a run that never reports one leaves the reading absent rather than guessed.

end_run(reason='finished')[source]#

The fit is over; let whatever is still rising finish, and say why.

A run that was stopped and a run that finished leave the same picture behind, and the difference is the whole of what the user needs to know about it, so it is carried in rather than inferred.

apply_theme(colours)[source]#

Both plots, repainted in the new palette. Both of them.

A drawn spectrum belongs to the palette it was drawn in and nothing about a theme change reaches it on its own, so the well kept its old background while the map, the panel and every control around it changed: a black rectangle sitting in a light interface, which is exactly the kind of thing that reads as an unfinished application. It is redrawn by asking the reading thread for the same spaxel again, which is the one path that knows how to draw it, rather than by a second copy of that drawing code kept in step by hand.
