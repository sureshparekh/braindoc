brainsp.brain_gui#

BRAIN — desktop interface.

brainsp gui        (or python -m brainsp.brain_gui)

Pick a spectrum, set the ranges, paint masks straight onto the plot, fit.

Built on Qt rather than Tkinter because Tk on many Linux builds cannot reach the system’s TrueType fonts at all — every modern face falls back to a bitmap, which no amount of styling recovers. Qt renders them properly on Linux, macOS and Windows alike, and brings real stylesheets and icons with it.

Enable or disable a group of controls, carrying the reason on each.

A control that is live but whose value the run discards is the failure this interface is most exposed to, because the fit still finishes and the number still looks ordinary. Greying the control removes the possibility, and the tooltip answers the question the greying provokes.

brainsp.brain_gui.coverage_sentence(cov)[source]#

Why a library does or does not support the nebular modes, in a sentence.

Every number here is measured by io_utils.library_coverage from the template files themselves; this only chooses the words. Its own describe_coverage renders the same facts as an aligned block for a terminal, which does not fit a panel four hundred pixels wide.

brainsp.brain_gui.launch_screen()[source]#

Pick the monitor to open on.

Qt defaults to the primary screen, which on a multi-monitor desk is routinely not the one in front of the user. Prefer the screen holding the launching terminal, then the screen under the pointer, and only fall back to primary when neither can be determined.

class brainsp.brain_gui.FitThread(cfg, device, cache_engine=True, cache_templates=True)[source]#

Bases: ChildRun

One fit, in a process of its own, watched from a thread of its own.

The interface used to run the fit in this thread and set JAX_PLATFORMS just before it, which chose nothing: by then JAX had been used in this process and its backend was already fixed. The configuration now goes to a fresh interpreter whose environment names the platform before it starts, which is the only moment the variable is read, and that interpreter refuses to fit at all if it did not get the device asked for.

The two caching settings are carried here rather than read from the settings file, because this is the only place in the interface that could honour them and a caching tick box that the fit ignored would be another control with no effect. They are honoured in the child, which is where the loader they replace now lives.

Whatever the fit prints comes back as log messages and is written to this process’s own output, so a BRAIN started from a terminal still shows its progress there.
