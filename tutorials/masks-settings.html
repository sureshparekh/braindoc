Masks and settings files#

Two habits that make fits better and easier to repeat: masking what the model cannot describe, and keeping the settings, and the whole run, in files.

The whole tutorial as one file, ready to run: 05_masks_settings.py.

Mask the emission lines in spop#

A fit of the stars alone (spop) has no emission lines in its model, so an unmasked line is light the stars must try to reproduce. The standard optical mask leaves out the usual lines and sky residuals:

import brainsp

spectrum = "examples/spectra/mock_star_forming_lines.spec"
print(open("examples/masks/emission_lines.sm").read())
regions = brainsp.read_mask("examples/masks/emission_lines.sm")[0]
print(f"{len(regions)} regions read")

unmasked = brainsp.fit_spectrum(spectrum, output_dir="fits/nomask", quiet=True)
masked = brainsp.fit_spectrum(spectrum, output_dir="fits/mask", quiet=True,
                              mask="examples/masks/emission_lines.sm")
print(f"spop, no mask   : sigma {unmasked.sigma:6.1f}  A_V {unmasked.av:.3f}  chi2 {unmasked.chi2:.3f}")
print(f"spop, lines out : sigma {masked.sigma:6.1f}  A_V {masked.av:.3f}  chi2 {masked.chi2:.3f}")

Your own mask#

brainsp.write_mask("my_mask.sm", [
    (5570.0, 5590.0, 0.0, "sky [O I] 5577"),
    (3910.0, 3990.0, 2.0, "Ca II H and K, double weight"),
] + [(lo, hi, 0.0, "") for lo, hi in brainsp.STANDARD_OPTICAL_MASK])
print(open("my_mask.sm").read())

A weight of 0 excludes a region, and 2 counts it double (Wavelength masks).

Settings in a file#

import subprocess, sys

s = brainsp.Settings()
print(len(brainsp.Settings.names()), "settings")
print(brainsp.Settings.describe("dispersion_range"))

s = brainsp.Settings(nebular_mode="espop", wavelength_scale="vacuum")
s.dust_range = [0.0, 3.0]
s.ages = [1e7, 1e8, 1e9, 5.01e9, 1.26e10]
print(s)                      # only what differs from the defaults
try:
    s.dust_rnge = [0, 1]
except KeyError as error:
    print("KeyError:", error)

s.copy(spectrum="examples/spectra/mock_star_forming_lines.spec").validate()
print("valid")
s.save("my_settings.yaml")
print(brainsp.Settings("my_settings.yaml") == s)

The run as one file#

brainsp.write_script("run_my_spectra.py", settings=s, spectra=[
    "examples/spectra/mock_star_forming_lines.spec",
    ("examples/spectra/mock_observed_frame.spec",
     dict(spectrum_redshift=0.03, spectrum_in_rest_frame=False, galactic_ebv=0.05))])
done = subprocess.run([sys.executable, "run_my_spectra.py", "--check"],
                      capture_output=True, text=True)
print(done.stdout.strip())
lines = open("run_my_spectra.py").read().splitlines()
print(f"run_my_spectra.py: {len(lines)} lines")

A misspelt setting is refused with the nearest valid name, so it can never silently stay at its default. The script holds every setting under its documentation, the mask and both spectra with their own corrections; python run_my_spectra.py runs it anywhere brainsp is installed (A run as one file). The file it wrote is here: run_my_spectra.py.
