4. Observed-frame spectra, corrections and batches#

Two things happen to light on its way to the telescope that BRAIN undoes before fitting: the redshift, and the Milky Way’s dust. The galaxy’s own dust is not undone: it is fitted. mock_observed_frame.spec is mock_old_population.spec as observed: shifted to \(z = 0.03\) and reddened by \(E(B-V) = 0.05\) of Galactic dust.

"""Tutorial 4: observed-frame spectra, corrections and batches."""
import time
import brainsp

folder = "examples/spectra"

# One spectrum still in the observed frame, behind Milky Way dust: BRAIN
# removes the Galactic reddening at the observed wavelengths, then the
# redshift, then fits.
r = brainsp.fit_spectrum(f"{folder}/mock_observed_frame.spec",
                         output_dir="fits/observed", quiet=True,
                         spectrum_redshift=0.03,
                         spectrum_in_rest_frame=False, galactic_ebv=0.05)
rest = brainsp.fit_spectrum(f"{folder}/mock_old_population.spec",
                            output_dir="fits/observed", quiet=True)
print(f"observed frame: v0 {r.v0:.2f}  sigma {r.sigma:.2f}  A_V {r.av:.3f}")
print(f"rest-frame twin: v0 {rest.v0:.2f}  sigma {rest.sigma:.2f}  "
      f"A_V {rest.av:.3f}")

# The corrections table, as the interface loads it.
print("\ncorrections.csv:")
print(open(f"{folder}/corrections.csv").read())
table = brainsp.read_corrections_table(f"{folder}/corrections.csv")
for path, values in table.items():
    print(f"  {path.split('/')[-1]:30s} {values}")

# A batch: every spectrum, each with its own corrections, in one process.
# The fit is compiled once and every later spectrum reuses it.
spectra = [p for p in table if "seyfert" not in p
           and "star_forming" not in p]
start = time.time()
results = brainsp.fit_spectra(spectra, corrections=table,
                              output_dir="fits/batch", quiet=True)
print(f"\n{len(results)} spectra in {time.time() - start:.1f} s")
for res in results:
    print(f"  {res!r}")

The observed-frame spectrum, once BRAIN has removed the Galactic dust at the observed wavelengths and divided the wavelengths by \(1 + z\), gives the same fit as its rest-frame twin to within the noise. The order matters, and BRAIN follows the light backwards: Galactic dust acts on the light as it arrives, at observed wavelengths, so it is removed first, then the redshift. See Pre-fit corrections.

The corrections table#

A CSV file with the spectrum’s name first and any of redshift (or z), ebv, rv, law and rest_frame, the same table the interface loads. A redshift in the table is one BRAIN removes, unless rest_frame says the spectrum is already at rest. brainsp.read_corrections_table() reads it; brainsp.fit_spectra() takes it as corrections=.

Batches#

brainsp.fit_spectra() fits a list (or a glob pattern) of spectra, each with its own corrections, and returns one result per spectrum in order; a spectrum that fails gives a result whose error_message says why, and the rest carry on. It keeps the fit warm: on a GPU every spectrum after the first reuses the compiled fit (about 0.5 s each for spop); on a CPU with many spectra it fits them on worker processes, one per core (Many spectra). Here three spectra took 2.4 s together.
