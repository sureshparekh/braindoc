Tutorials#

Complete worked examples, each a short Python script run from start to finish on the mock data whose right answers are known. The code on each page is the script as it ran, and the output and figures are what it produced when this site was built, so what you see is what you will get.

Before you start#

The tutorials run in a working folder of your choice and share the mock data written by the first one:

mkdir brain_tutorials && cd brain_tutorials
python -c "import brainsp; brainsp.mock.write_examples('examples')"

Each script is a file of its own: copy the code of a page into a file and run it with python, or paste it into a notebook cell. A GPU makes them faster but is not needed; each takes from a few seconds to two minutes on a CPU.

The scripts, ready to run#

Every tutorial is also a short Python file, with a comment on what each step does. Each one writes the mock data itself if it is missing, so any of them runs on its own in an empty folder (tutorial 7 reads the cube that tutorial 6 fits).

unzip brain_tutorials.zip && cd brain_tutorials
python 01_first_spectrum.py

The tutorials#

1 · A first spectrumFit an old stellar population, read every number, compare it with the truth and draw the fit and the star formation history.2 · Emission linesFit a star-forming galaxy in espop: gas kinematics, line fluxes in each unit, and its place on the BPT diagram.3 · An active nucleusWhat an AGN continuum does to a fit without AGN templates, and how adding them recovers the host.4 · Many spectraA table of spectra with their own redshifts and reddening, fitted in one call.5 · Masks and settings filesMask sky lines, up-weight a feature, keep the settings in a file, and write the run as a script.6 · A datacubeA 16 × 16 mock datacube from start to megacube: S/N masks, the fit, and the recovered maps against the truth.7 · Exploring a megacubeMaps, single spaxels, star formation histories and the BPT and WHAN diagrams from a fitted cube.8 · On a server or a clusterRun BRAIN without a display: SLURM jobs, GPUs, many cubes, and how BRAIN shares the machine.9 · The interface, end to endThe same spectrum and cube, fitted entirely in the desktop interface.
