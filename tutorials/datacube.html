A datacube#

This tutorial fits the 16 × 16 mock datacube from start to megacube and compares the recovered maps with the maps it was built from. The cube is MaNGA-like (logarithmic wavelengths in vacuum, FLUX, IVAR and MASK extensions) at \(z = 0.02\), with a rotating disc whose velocity, dispersion, extinction and populations change across the field, and star-forming emission lines.

The whole tutorial as one file, ready to run: 06_datacube.py.

Look at the file#

import time
import numpy as np
from astropy.io import fits
import brainsp

cube = "examples/cube/mock_cube.fits"
with fits.open(cube) as h:
    h.info()
    print("wavelengths:", h["WAVE"].data[0].round(1), "...",
          h["WAVE"].data[-1].round(1), "A,", len(h["WAVE"].data), "pixels")

The pipeline#

pipeline = brainsp.CubePipeline(
    cube,
    redshift=0.02,                       # the galaxy's z (required)
    settings=brainsp.Settings(nebular_mode="espop"),
    wavelength_scale="vacuum",           # MaNGA-like: vacuum
    sn_mask=[3, 10, 20],                 # S/N masks to compute
    fit_sn_threshold=3,                  # fit spaxels with S/N > 3
    wavelength_mask=None,                # or a .sm file, or regions
    output_dir="cube_out")
pipeline.validate()
start = time.time()
written = pipeline.run(log=lambda line: None)
print(f"\n{written[0]}\nin {time.time() - start:.0f} s")

validate() checks the whole run before anything is fitted: the extensions exist, the redshift is given, the wavelength scale is answered, the S/N mask the fit reads is one that will be written. run() then computes the S/N masks, fits every spaxel above S/N 3 and writes the megacube (Fitting a datacube). log= receives each line of the run’s log; here it is silenced.

The maps, against the truth#

c = brainsp.read_megacube(written[0])
for group, names in c.groups.items():
    print(f"{group:15s} {len(names):3d} maps, e.g. {names[:4]}")

truth = fits.open(cube.replace(".fits", ".truth.fits"))
fitted = np.isfinite(c.plane("vrot_star"))
print(f"\n{fitted.sum()} spaxels fitted")
for label, plane, key in (("velocity", "vrot_star", "V"),
                          ("dispersion", "Sigma_star", "SIGMA"),
                          ("A_V", "Av", "AV")):
    d = (c.plane(plane) - truth[key].data)[fitted]
    print(f"{label:10s}: fit - truth  median {np.median(d):7.3f}, "
          f"rms {np.sqrt(np.mean(d ** 2)):6.3f}")

pipeline.export_script("run_mock_cube.py")
print("\nthe same run as one file: run_mock_cube.py")

In the brightest spaxels the offset is about 3 per cent of a dispersion of 100–160 km s⁻¹. Dispersions from faint spaxels are the least constrained quantity of a cube fit; weight a dispersion map by its error map ("Sigma_star error") before reading structure into it. The run is also saved as one file, run_mock_cube.py, which repeats it with python run_mock_cube.py.
