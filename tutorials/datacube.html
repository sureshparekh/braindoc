7. A datacube#

The mock datacube mock_cube.fits is 16 x 16 spaxels laid out like a MaNGA LOGCUBE (FLUX, IVAR, MASK and WAVE extensions, a logarithmic wavelength axis at 69 km/s per pixel, sky coordinates) and built as a galaxy: a disc rotating at 220 km/s seen at 55° inclination, an old bulge with a high velocity dispersion, a ring of young stars, dust and star formation at 5 spaxels, a LINER-like nucleus, and a signal-to-noise falling from 58 at the centre to 3 at the edge. The truth is in mock_cube.truth.fits.

"""Tutorial 7: a datacube."""
import time
import numpy as np
from astropy.io import fits
import brainsp

cube = "examples/cube/mock_cube.fits"
with fits.open(cube) as h:
    h.info()
    print("wavelengths:", h["WAVE"].data[0].round(1), "...",
          h["WAVE"].data[-1].round(1), "A,", len(h["WAVE"].data), "pixels")

pipeline = brainsp.CubePipeline(
    cube,
    redshift=0.02,                       # the galaxy's z (required)
    settings=brainsp.Settings(nebular_mode="espop"),
    wavelength_scale="vacuum",           # MaNGA-like: vacuum
    sn_mask=[3, 10, 20],                 # S/N masks to compute
    fit_sn_threshold=3,                  # fit spaxels with S/N > 3
    wavelength_mask=None,                # or a .sm file, or regions
    output_dir="cube_out")
pipeline.validate()
start = time.time()
written = pipeline.run(log=lambda line: None)
print(f"\n{written[0]}\nin {time.time() - start:.0f} s")

c = brainsp.read_megacube(written[0])
for group, names in c.groups.items():
    print(f"{group:15s} {len(names):3d} maps, e.g. {names[:4]}")

truth = fits.open(cube.replace(".fits", ".truth.fits"))
fitted = np.isfinite(c.plane("vrot_star"))
print(f"\n{fitted.sum()} spaxels fitted")
for label, plane, key in (("velocity", "vrot_star", "V"),
                          ("dispersion", "Sigma_star", "SIGMA"),
                          ("A_V", "Av", "AV")):
    d = (c.plane(plane) - truth[key].data)[fitted]
    print(f"{label:10s}: fit - truth  median {np.median(d):7.3f}, "
          f"rms {np.sqrt(np.mean(d ** 2)):6.3f}")

pipeline.export_script("run_mock_cube.py")
print("\nthe same run as one file: run_mock_cube.py")

What the pipeline did#

brainsp.CubePipeline describes the whole run: which cubes, at which redshift, through which preparation stages, with which fit settings, written where. Here it:

  1. divided each spaxel’s wavelengths by \(1 + z = 1.02\);

  2. computed the signal-to-noise of every spaxel over 4000–6000 Å (rest) and wrote masks for S/N > 3, 10 and 20 (SN_MASKS_3, …) and the continuous map SNMAP;

  3. fitted every spaxel with S/N > 3, 172 of the 256, in espop;

  4. wrote mock_cube-BRAIN_MEGACUBE.fits.

The recovered maps match the truth: median offsets of 0.8 km/s in velocity, 0.1 km/s in dispersion and 0.01 mag in \(A_V\), with an rms of 6 km/s, 8 km/s and 0.05 mag, the scatter expected at these signal-to-noise ratios.

The stages a real cube may need, Galactic dereddening, spatial binning, resolution matching, spectral resampling and filtering, are options of the same object; Datacubes describes each.

The same run, as a file#

pipeline.export_script("run_mock_cube.py") wrote the run as one Python file. Its pipeline section:

PIPELINE = dict(

    # The datacubes; relative paths are taken from this file's folder.
    cubes=['examples/cube/mock_cube.fits'],

    # The galaxy's redshift: wavelengths are divided by 1 + z.
    # 0 for a cube already in the rest frame. Required, unless
    # PER_CUBE gives every cube its own.
    redshift=0.02,

    # Where the megacubes go; relative to this file's folder.
    output_dir='cube_out',

    # The extension holding the flux.
    flux_hdu='FLUX',

    # The extension holding the uncertainty.
    error_hdu='IVAR',

    # What error_hdu holds: inv_variance, variance, error or inv_error.
    error_type='inv_variance',

    # The extension of bad-pixel flags (None if there is none).
    mask_hdu='MASK',

    # air or vacuum: the cube's wavelength scale. Needed to place
    # emission lines (espop, nepop, photopop). MaNGA/SDSS: vacuum;
    # MUSE, CALIFA: air.
    wavelength_scale='vacuum',

    # Milky Way E(B-V) removed before anything else; 0 = off.
    galactic_ebv=0.0,

    # R_V of the Galactic reddening law.
    galactic_rv=3.1,

    # The Galactic reddening law (CCM, ...).
    galactic_law='CCM',

    # Bin spaxels n x n; None = off.
    spatial_binning=None,

    # Smooth the data to a coarser resolution (to reproduce an older
    # run; it correlates the noise). None = off.
    degrade_resolution=None,

    # Resample the wavelength axis; None = off.
    spectral_binning=None,

    # Spatial low-pass Butterworth filter {order, range}; None = off.
    # It mixes neighbouring spaxels.
    butterworth=None,

    # Signal-to-noise masks to compute: thresholds, the window (Angstrom,
    # rest frame) and the method; None = off.
    sn_mask=[3, 10, 20],

    # Fit only spaxels above this S/N (one of the thresholds);
    # None = every spaxel with data.
    fit_sn_threshold=3,

    # (start, end, weight) regions applied to every spaxel, or a mask file.
    wavelength_mask=None,

    # Spaxels fitted at once; None = automatic.
    batch_size=None,

    # Age bins of the PoPBins maps: (name, youngest yr, oldest yr).
    population_bins=None,

    # Step, in Angstrom, of the linear grid FLXOBS and FLXSYN are written on.
    flxobs_step=None,

    # Star-formation-rate maps: (name, min yr, max yr), Msun/yr;
    # need galaxy_distance. None = none.
    sfr_bins=None,

    # Featureless power laws grouped by exponent: (name, min, max).
    fc_bins=None,

    # Blackbodies grouped by temperature: (name, min K, max K).
    bb_bins=None,

    # Distance in Mpc, for Mstar, Mpcross and the SFRs (per cube:
    # a 'galaxy distance' column of per_cube). None = no masses.
    galaxy_distance=None,

    # The factor the cube's flux unit carries (1e-17 for MaNGA);
    # None = read from BUNIT.
    flux_scale=None,

    # Settings that differ from cube to cube, one dict per cube
    # (target, redshift, ebv, ...); None = none. Files in it are
    # relative to this file's folder.
    per_cube=None,

    # Re-run a cube whose megacube already exists.
    overwrite=True,

    # Record the pipeline inside each megacube.
    save_config=True,

    # Run the fit (False runs the preparation stages only).
    fit=True,
)
