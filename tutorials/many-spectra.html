Many spectra#

Real spectra come in the observed frame, behind the Milky Way’s dust, and rarely one at a time. This tutorial removes the redshift and the Galactic reddening of one spectrum, checks that it gives the same answer as its rest-frame twin, and then fits several spectra in one call, each with its own corrections from a table.

The whole tutorial as one file, ready to run: 04_many_spectra.py.

One spectrum in the observed frame#

The mock mock_observed_frame.spec is the old population of the first tutorial as it would be observed at \(z = 0.03\), behind Galactic dust of \(E(B-V) = 0.05\).

import time
import brainsp

folder = "examples/spectra"
r = brainsp.fit_spectrum(f"{folder}/mock_observed_frame.spec",
                         output_dir="fits/observed", quiet=True,
                         spectrum_redshift=0.03,
                         spectrum_in_rest_frame=False, galactic_ebv=0.05)
rest = brainsp.fit_spectrum(f"{folder}/mock_old_population.spec",
                            output_dir="fits/observed", quiet=True)
print(f"observed frame: v0 {r.v0:.2f}  sigma {r.sigma:.2f}  A_V {r.av:.3f}")
print(f"rest-frame twin: v0 {rest.v0:.2f}  sigma {rest.sigma:.2f}  A_V {rest.av:.3f}")

BRAIN removes the Galactic reddening at the observed wavelengths, then divides the wavelengths by \(1+z\), then fits (Corrections before the fit).

A table of corrections#

print(open(f"{folder}/corrections.csv").read())
table = brainsp.read_corrections_table(f"{folder}/corrections.csv")
for path, values in table.items():
    print(f"  {path.split('/')[-1]:30s} {values}")

The table is the same one the interface loads with Load table… and the command line reads with --corrections: one spectrum per row, then its redshift, \(E(B-V)\), \(R_V\) and law.

The batch#

spectra = [p for p in table if "seyfert" not in p and "star_forming" not in p]
start = time.time()
results = brainsp.fit_spectra(spectra, corrections=table,
                              output_dir="fits/batch", quiet=True)
print(f"\n{len(results)} spectra in {time.time() - start:.1f} s")
for res in results:
    print(f"  {res!r}")

The two spectra with emission lines are left out here because they need espop; a batch has one set of settings.

The observed-frame spectrum gives the same answer as its rest-frame twin, within the noise of each: the corrections are exact. Each spectrum of the batch writes its own files to fits/batch.

Larger batches#

fit_spectra() sorts the spectra into groups the fit would treat identically (the same settings, the same corrected wavelengths, the same usable pixels) and fits each group as one cube, which keeps a GPU busy; the rest are fitted one at a time, on worker processes when there is no GPU (Fitting many spectra). A spectrum that fails gives a result with error_message set, and the batch carries on.
