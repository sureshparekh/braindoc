6. Settings, and a run as one file#

Every choice BRAIN makes is a setting with a default. brainsp.Settings holds them all, checks every name, and documents each one.

"""Tutorial 6: settings, and a run as one Python file."""
import subprocess
import sys
import brainsp

# Every setting, with its default.
s = brainsp.Settings()
print(len(brainsp.Settings.names()), "settings")
print(brainsp.Settings.describe("dispersion_range"))

# Change a few, by name or by attribute.
s = brainsp.Settings(nebular_mode="espop", wavelength_scale="vacuum")
s.dust_range = [0.0, 3.0]
s.ages = [1e7, 1e8, 1e9, 5.01e9, 1.26e10]
print(s)                     # only what differs from the defaults
try:
    s.dust_rnge = [0, 1]
except KeyError as error:
    print("KeyError:", error)

# Validate without fitting (a spectrum is needed for a spectrum run).
s.copy(spectrum="examples/spectra/mock_star_forming_lines.spec").validate()
print("valid")

# Save and load: YAML, the same file brainsp fit --settings reads.
s.save("my_settings.yaml")
print(brainsp.Settings("my_settings.yaml") == s)

# The run as ONE Python file: every setting under its documentation.
brainsp.write_script("run_my_spectra.py", settings=s, spectra=[
    "examples/spectra/mock_star_forming_lines.spec",
    ("examples/spectra/mock_observed_frame.spec",
     dict(spectrum_redshift=0.03, spectrum_in_rest_frame=False,
          galactic_ebv=0.05))])
done = subprocess.run([sys.executable, "run_my_spectra.py", "--check"],
                      capture_output=True, text=True)
print(done.stdout.strip())
lines = open("run_my_spectra.py").read().splitlines()
print(f"run_my_spectra.py: {len(lines)} lines")

One file per run#

brainsp.write_script() writes a run as a single Python file: every setting, each under its own documentation; every spectrum with its own corrections; the wavelength mask inline. Paths inside the script’s folder are written relative to it, so the folder can be copied anywhere and run there. python run_my_spectra.py runs it, --check validates it and --device gpu chooses the processor. The interface’s Export run script writes the same kind of file. Its beginning:

"""
A BRAIN run: spectra.

Written by brainsp 2.0.0 on 2026-10-08 21:21. Every setting of the run is in this
file; edit it here and run it again:

    python run.py                  run it
    python run.py --check          check everything, fit nothing
    python run.py --device gpu     choose the processor: auto, cpu or gpu
    python run.py more/*.spec       fit these files instead

Each setting is documented where it is set. The same text, and more, is in
the BRAIN documentation (Settings reference), and in Python:
    import brainsp; print(brainsp.Settings.describe("dust_range"))
"""

import os
import sys

import brainsp

HERE = os.path.dirname(os.path.abspath(__file__))


def here(path):
    """A path written relative to this file's folder, made usable from any
    working directory. Absolute paths are left as they are."""
    return path if os.path.isabs(path) else os.path.join(HERE, path)

SETTINGS = brainsp.Settings(

    # ======================================================================
    # 1. WHAT TO FIT
    # ======================================================================

    # Optional list of wavelength regions to treat specially — sky lines, bad
    # columns, or features you want the fit to try harder on. One region per line:
    #
    #       start_wavelength   end_wavelength   [weight]
    #
    # The weight is optional and defaults to 0, meaning the region is thrown away.
    # A weight above 1 makes those pixels count for more; 2 counts them double.
    # A .sm / .gm mask file works as it is: its first line is the number of
    # regions N, and only the N lines after it are read; anything below them is
    # treated as notes.
    # For a datacube the same mask is applied to every spaxel.
    # Leave blank for no mask. The desktop interface can draw one for you.
    mask=None,

    # ======================================================================
    # 2. WAVELENGTH RANGE
    # ======================================================================

    # Fit only between these wavelengths, in Angstroms. Trim the noisy ends of
    # your spectrum here. Leave blank to use everything.
    #
    # Changing this changes the size of the problem, so BRAIN rebuilds its
    # compiled engine once (a few seconds). Keeping one range across a batch
    # keeps every run fast.
    wavelength_min=3700.0,

Every setting is listed, not only the ones you changed; a changed value is marked with its default (# default: ...), so the file is also the record of exactly how a result was made.
