The desktop interface#

The interface fits spectra and datacubes and explores the results, without code. It is a guided window: each task is a row of numbered steps, done from left to right, and each step shows on one line whether it has what it needs. Behind it is the same engine as the Python library, so a fit made here gives the same numbers as the same fit made in code, and a run set up here can be saved as a Python file.

brainsp gui

The window#

The top bar holds, from left to right:

  • the three workspaces: Spectrum, Datacube and Results;

  • the status of the current run (ready, fitting…, or what was last done);

  • the device selector: auto (a GPU when one is visible), cpu or gpu (Starting the interface);

  • the theme switch, between the light and the dark theme;

  • the workspace’s main action: Fit spectrum in the Spectrum workspace.

The step bar shows the workspace’s steps. Each shows its name, a one-line summary of what it is set to, and a round mark: a green tick when the step is ready; a red !, with the summary in red, when it needs an answer; and the step’s own icon in grey while it is still to do (its name is dimmed when there is nothing to do in it). The open step is a raised card with its mark filled. Click a step to open it; Next and Back at the bottom of the panel move through them in order.

The panel on the left holds the current step’s controls, grouped in sections. Each section is tagged Required (it must be answered) or Optional (it has a sensible default). Hovering over a control shows what it does.

The view on the right shows the data the workspace works on: the spectrum in the Spectrum workspace, the cube’s map and the clicked spaxel’s spectrum in the Datacube workspace, and the maps and diagrams in the Results workspace. It stays in place as you move through the steps.

The three workspaces#

SpectrumFit one spectrum, or every spectrum of a table, in five steps.DatacubePrepare and fit one datacube or many, in six steps, and watch it being fitted.ResultsOpen a megacube: maps, spaxel spectra, star formation histories, BPT and WHAN.

The Model step is shared: the Spectrum and the Datacube workspaces show the same model panel, so a spectrum and a cube are fitted with the same physics unless you change it (The model panel).

What the interface does not show#

The interface exposes the settings most fits need. Every other setting (the instrumental resolution of a single spectrum, the line groups and their kinematic ranges, multi-component lines, the nebular gas properties, the solver’s tolerances and others) is available from Python, from a settings file and from the command line; Settings lists them all. A run exported from the interface (Exporting maps and runs) is a Python file holding every setting, so it is also the easiest way to change one the window does not show.
