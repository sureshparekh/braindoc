Starting the interface#

Open it#

brainsp gui                # from any terminal where brainsp is installed
brainsp-gui                # the same, as a program of its own

To start it from your desktop’s applications menu instead, add it once with brainsp desktop (Installation). The window opens on the Spectrum workspace, listing the spectra of the examples folder (~/.brainsp/examples/spectra, written by brainsp examples) until you choose another folder with the folder button of step 1.

Where results go#

Workspace

Results are written to

Spectrum

a folder brain_out in the folder BRAIN was started from; step 5 Fit shows the exact path

Datacube

the Output folder of step 1 Cubes (brain_ifu_out by default)

Results

nothing is written, except the maps and figures you export

The device#

The device selector in the top bar decides where the next fit runs: auto (a GPU when JAX can see one, the CPU otherwise), cpu or gpu. Every fit runs in a process of its own, started for it, so a change of device always takes effect at the next fit, whatever ran before. The choice changes the speed, never the numbers. On the CPU, BRAIN never uses more than all but two of the machine’s cores, so the desktop stays usable during a long run (CPUs and GPUs).

The theme#

The button with the moon (or the sun) switches between the light and the dark theme. Every control, plot and dialog follows. These pages show both: the screenshots follow the theme you read them in.

The mouse and the keyboard#

On every plot of the interface:

On a spectrum

On a map

scroll wheel

zoom the wavelength axis around the pointer

zoom around the pointer

drag

mark a wavelength region (in the Masks step)

pan, when zoomed in

right-click inside a region

remove the region

click

choose a spaxel

double-click

show the whole range

show the whole field

arrow keys

move the chosen spaxel (with Shift, by ten)

The toolbar above a spectrum (home, pan, zoom) does the same with Matplotlib’s own tools. In the Spectrum workspace, the bar at the bottom of the window shows the value under the pointer and the headline numbers of the last fit: \(A_V\), \(\sigma\), \(v_0\), \(\chi^2/N\) and the mean deviation.

Stopping a fit#

A fit runs outside the window, so the interface stays responsive while it runs. In the Datacube workspace, Stop ends the run at once: the megacubes already written stay written, and the one in progress is not written, because a megacube is only ever written whole.
