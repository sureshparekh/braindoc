Fitting a spectrum#

The Spectrum workspace fits one spectrum in five steps: Spectrum, Corrections, Masks, Model and Fit. Steps 2 and 3 are optional and can be skipped; step 4 has sensible defaults for everything but the fitting mode.

Step 1: Spectrum#

Control

What it does

filter by name…

narrows the list to the files whose name contains the text

folder button

opens another folder of spectra

Load table…

reads a table of spectra, each with its own redshift and reddening (Fitting a table of spectra)

the list

clicking a file draws it on the right

Wavelength scale

whether the file’s wavelengths are in air or in vacuum

The files are plain text: wavelength in Å, flux and, optionally, error and quality flag (Your data).

The Wavelength scale is asked in step 1, with the data, whatever the mode: it is a fact about the file, so it is settled before the model is chosen. espop and nespop place the lines’ rest wavelengths on the scale you give and do not run without it; spop places no lines and does not use it. SDSS, MaNGA, DESI and LAMOST spectra are on vacuum wavelengths; MUSE, CALIFA and most ground-based optical spectrographs are on air. A wrong answer shifts every gas velocity by about 83 km s⁻¹ and nothing else in the output reveals it, so the answer is required and BRAIN never guesses.

Step 2: Corrections#

Control

What it does

Redshift z

the galaxy’s redshift

The spectrum is already in the rest frame

ticked (default): you removed the redshift yourself, and BRAIN only uses \(z\) to find the instrument’s resolution at the observed wavelength. Unticked: BRAIN divides the wavelengths by \(1+z\) before fitting

Galactic E(B−V)

the Milky Way’s reddening along the line of sight, for example from the Schlafly & Finkbeiner (2011) maps; 0 leaves it

R_V

\(R_V\) of the Milky Way’s dust; 3.1 is the average

Law

the Milky Way’s extinction law, CCM by default

The Galactic reddening is removed at the observed wavelengths, and then the redshift if you asked for it. The galaxy’s own dust is not a correction: it is fitted, in step 4.

Step 3: Masks#

Drag across the plot, or across the thin strip below it, to mark a region; right-click inside a region to remove it. The weight of each new region is chosen above the list: exclude 0 leaves its pixels out, normal 1 leaves them as they are, emphasise 2 counts them double. Wavelength masks describes the buttons and the file formats.

Warning

Masks apply in every mode. When you fit emission lines (espop, nespop), do not mask the lines you want measured.

Step 4: Model#

The model is shared with the Datacube workspace: a spectrum and a cube are fitted with the same physics unless you change it. Its panels, from the top, are Nebular treatment, Stellar templates, Fitting range, Dust, Kinematics and Fit quality. The model panel describes every control; in brief:

  • Nebular treatment: spop, espop or nespop (The three fitting modes). Choosing nespop selects a library that can run it.

  • Stellar templates: the library, the range of ages and of metallicities, and whether to add the seven AGN continuum templates. The number of templates is counted below.

  • Fitting range: the wavelengths fitted, and the normalisation wavelength \(\lambda_0\).

  • Dust: the extinction law, and the range \(A_V\) may take.

  • Kinematics: the ranges of the stellar velocity and dispersion.

  • Fit quality: smoothness, the number of error samples, and outlier rejection.

Step 5: Fit#

Control

What it does

Ready to fit

a summary of the run; it reads Not ready, and the step shows !, while something above is missing

Also save a PDF plot

also writes the standard figure, <name>_fit.pdf

results path

where the files go: brain_out in the folder BRAIN was started from

Fit every spectrum in the table

shown when a table is loaded; fits them all (Fitting a table of spectra)

Export run script…

writes the run as one Python file (Exporting maps and runs)

Fit spectrum (top bar)

runs the fit

When the fit finishes, the model is drawn over the data and the numbers appear in the bar at the bottom of the window; A fitted spectrum explains what you see and where the files are.
