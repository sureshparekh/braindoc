Running a datacube#

Step 6 Run of the Datacube workspace runs the pipeline and shows it running: each spaxel takes the accent colour on the map as it is fitted, a progress bar fills, and the run’s own log scrolls underneath.

The Run panel#

Control

What it does

Run the pipeline

validates the whole run, then starts it

Stop

ends the run at once; megacubes already written stay written, and the one in progress is not written

Check

validates the whole pipeline without running it, and shows every problem in the panel that caused it

Load… / Save…

reads or writes the whole pipeline (every step’s settings) as a file

Reset

returns every setting of the workspace to its default

Export run script…

writes the run as one Python file, to run without the window (Exporting maps and runs)

View results

opens the megacube the run wrote in the Results workspace (Exploring a megacube)

Before the run#

Run the pipeline first checks everything at once: the extensions exist, the redshift is given, the wavelength scale is answered when lines are fitted, the S/N mask the fit reads is one that will be written, every column of the targets table is read by some stage. A problem is shown inside the panel that caused it, with what to change, and the run does not start. Check does the same without running.

During the run#

The log names each stage as it runs and, during the fit, reports the spaxels done, their rate and the time left. On a GPU the spaxels go through a queue sized to the card; on a CPU they are spread over worker processes, one per physical core and never more than all but two cores. Either way every spaxel gets the same fit (CPUs and GPUs). With several cubes in the table, they run one after another, and the CPU workers stay warm from one to the next.

The Outputs panel#

Below the Run panel, the Outputs panel (optional) sets what the megacube holds beyond the fit itself:

Control

What it does

Population bins

the age bins of the PoPBins maps: a name and the youngest and oldest age of each (bins may overlap)

Spectra step [Å]

the step of the linear wavelength grid FLXOBS and FLXSYN are written on

After the run#

View results opens the megacube in the Results workspace. The file is <cube>-BRAIN_MEGACUBE.fits in the output folder, and it holds every map, the observed and model spectra, the population vectors, the emission-line products and the uncertainties (Megacube files).
