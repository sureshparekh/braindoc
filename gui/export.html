Exporting maps and runs#

The interface exports two kinds of thing: maps and figures, for a paper or another program, and the run itself, as a Python file that repeats it without the window.

Maps#

In the Datacube workspace, the map above the cube has an Export map… button.

Control

What it does

this plane / every plane

export the map shown, or every plane of its extension

PNG

an image for a screen or a draft

PDF

a vector image for the paper

FITS

the numbers, with the cube’s sky coordinates and a TRUST extension whose bits say why a spaxel is not a measurement (not fitted, no value), so the file can be read without the megacube

Folder

where the files go

Write the files

writes them

In the Results workspace, Export… above each map and above the spaxel panel saves that figure as it is shown.

The same exports are one call in Python, brainsp.plots.export_maps(), or one command, brainsp plot MEGACUBE --export FOLDER --formats png,pdf,fits (Figures).

The run, as a Python file#

Both fitting workspaces have Export run script…: in step 5 Fit of the Spectrum workspace, and in the Run panel of step 6 of the Datacube workspace.

It writes one Python file that holds every setting of the run, the wavelength mask, and the spectrum (or every spectrum of the loaded table, each with its own corrections) or the datacubes and every stage of the pipeline. A datacube run also writes its settings file beside the script. Run it with

python run_brain.py            # fit, as the window would have
python run_brain.py --check    # validate only
python run_brain.py --device gpu

wherever brainsp is installed: on this computer, on a server, or in a cluster job.

Save it in the folder that holds your data. Paths inside that folder are written relative to it, so the folder can be copied to another machine and run there as it is. Files outside it are listed under the button, because they will not travel with the folder.

The script is also the way to change a setting the window does not show: open it, find the setting in its SETTINGS block, change it and run it (A run as one file).
