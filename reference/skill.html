The Claude skill#

The repository includes a skill for Claude (Claude Code, the Claude apps and the API): skill/brainsp/SKILL.md. It teaches Claude how to use BRAIN: every recipe on these pages in compact form, the command line, and, above all, the conventions that change numbers if missed (the wavelength scale, the cube redshift, the units and extinction convention of line fluxes, observed versus intrinsic dispersions, apparent masses, how masks and S/N cuts are read). With it installed, asking Claude to “fit these MaNGA spectra with BRAIN and make a BPT map” gets BRAIN used correctly.

Installing it#

Claude Code, for yourself (every project):

mkdir -p ~/.claude/skills
cp -r skill/brainsp ~/.claude/skills/

Claude Code, for one project (shared with everyone who clones it):

mkdir -p .claude/skills
cp -r skill/brainsp .claude/skills/

Claude Code finds skills in those folders at start-up; /skills lists them.

Claude.ai and the Claude apps: zip the folder (cd skill && zip -r brainsp.zip brainsp) and upload it under Settings → Capabilities → Skills.

The API: upload it as a custom skill with the Skills API and enable it for the conversation.

The skill only describes BRAIN; it runs nothing by itself. BRAIN must be installed where Claude runs the code.

# BRAIN (`brainsp`)

BRAIN fits a galaxy spectrum, or every spaxel of a datacube, with a
non-negative mix of simple-stellar-population templates, broadened and
shifted by a Gaussian LOSVD and attenuated by dust, optionally with emission
lines, a nebular continuum and AGN power laws. JAX; CPU or GPU; float64.
Package `brainsp` (import name), commands `brainsp` and `brainsp-gui`.
Documentation: `documentation/` in the repository (Sphinx), built HTML in
`documentation/build/html`.

## Before anything

- Installed? `python -c "import brainsp; print(brainsp.__version__)"`.
  Not installed: `pip install git+https://github.com/sureshparekh/brainv1`
  (or `pip install -e .` in a clone). Check: `brainsp selftest --quick`.
- Mock data with known answers, for trying anything:
  `folder = brainsp.mock.write_examples()` (→ `~/.brainsp/examples`:
  `spectra/*.spec` with `.truth.json`, `spectra/corrections.csv`,
  `masks/emission_lines.sm`, `cube/mock_cube.fits` 16x16 at z = 0.02, vacuum).
- **Choose the device before the first fit in a Python process**:
  `brainsp.set_device("cpu"|"gpu"|"auto")` or `device=` on the first call.
  JAX fixes it at first use; changing later raises. `import brainsp` and
  `brainsp.mock` never start JAX.

## Recipes

One spectrum (text file: wavelength Å, flux, [error], [flag 0=good]):

```python
import brainsp
r = brainsp.fit_spectrum("g.spec", output_dir="out", quiet=True)      # spop
r.v0, r.sigma, r.av, r.chi2, r.adev
r.mean_log_age_light, r.mean_log_age_mass, r.mean_metallicity_light
p = r.populations          # structured: x, mini, mcor, age, Z, mstars, name, stellar
```

Emission lines (requires the spectrum's wavelength scale):

```python
r = brainsp.fit_spectrum("g.spec", nebular_mode="espop", wavelength_scale="vacuum")
r.v_gas, r.sigma_gas
r.lines["Halpha_6563"]                          # (flux, err) as written: see conventions
obs = r.line_fluxes(units="input", observed=True)   # physical, as observed
```

AGN continuum: `include_power_law=True` (7 templates); `r.agn_fraction` (%).

Observed-frame spectrum + Milky Way dust:
`spectrum_redshift=z, spectrum_in_rest_frame=False, galactic_ebv=E, galactic_rv=3.1`.

Many spectra (one compile, warm; CPU → worker processes automatically):

```python
rs = brainsp.fit_spectra("spec/*.spec", s, corrections="corrections.csv",
                         output_dir="out")       # CSV: filename,redshift|z,ebv,rv,law,rest_frame
bad = [x for x in rs if x.error_message]
```

Settings object (checked names; YAML round trip; describe):

```python
s = brainsp.Settings(nebular_mode="espop", wavelength_scale="vacuum")
s.dust_range = [0, 3]; s.validate(); s.save("s.yaml"); brainsp.Settings("s.yaml")
print(brainsp.Settings.describe("velocity_range")); brainsp.Settings.names()
```

Datacube:

```python
p = brainsp.CubePipeline("cube.fits", redshift=0.02,          # redshift REQUIRED (0 = at rest)
        settings=brainsp.Settings(nebular_mode="espop"), wavelength_scale="vacuum",
        flux_hdu="FLUX", error_hdu="IVAR", error_type="inv_variance", mask_hdu="MASK",
        galactic_ebv=0.0, sn_mask=[3, 5, 10], fit_sn_threshold=3,
        wavelength_mask="lines.sm",           # or [(lo, hi, weight), ...]; every spaxel
        output_dir="mega")
p.validate(); out = p.run()                   # -> ['mega/cube-BRAIN_MEGACUBE.fits']
cube = brainsp.fit_cube("cube.fits", 0.02, wavelength_scale="vacuum")   # short form
```

Per-cube values: `per_cube="targets.csv"` (`target,redshift,ebv,rv,law,mask file,...`).
Stages (all off by default): `spatial_binning=n`, `degrade_resolution={...}`,
`spectral_binning=step`, `butterworth=True|{order,range}`, `galactic_ebv`.

Reading a megacube:

```python
c = brainsp.read_megacube("mega/cube-BRAIN_MEGACUBE.fits")
c.names(); c.groups        # Populations, Kinematics, Fit quality, Emission lines, Diagnostics
v = c.plane("vrot_star")   # NaN where unfitted. Also Sigma_star, Av, Mage_L, Mage_M, MZ_L,
                           # xyy..xo _light/_mass, "Halpha_6563  flux" (TWO spaces),
                           # "... EW", "... velocity", "... sigma", "BPT [N II]", "WHAN"
obs, model, lines = c.spectrum(y, x); light, mass = c.populations(y, x); c.ages
```

Figures (any format by suffix; return Figure; `ax=` to embed):

```python
P = brainsp.plots
P.spectrum(r, "fit.png", xlim=(6450, 6700)); P.sfh(r, "sfh.png"); P.spectrum_fit(r)
P.map(c, "vrot_star", "v.pdf", cmap="RdBu_r", scale="full")      # scale clip|full|log
P.maps(c, ["vrot_star", "Av", "Mage_L"], "page.png")
P.export_maps(c, "maps", formats=("png", "pdf", "fits"))         # FITS: WCS + TRUST mask
P.spaxel(c, y, x, "s.png"); P.sfh(c, "sfh.png", y=y, x=x)
P.diagnostic(c, "BPT [N II]", "bpt.png")                         # or "BPT [S II]", "WHAN"
```

A run as one Python file (for servers; `python run.py [--check] [--device gpu]`):
`brainsp.write_script("run.py", settings=s, spectra=[...])`,
`p.export_script("run_cube.py")`, `brainsp init run.py spec/*.spec`.
Paths inside the script's folder are written relative to it and resolved
from the script's location: save the script beside the data, copy the folder
to the server, run it there from anywhere. Paths outside are listed in a
`# NOTE` at the top of the script.

Masks: `regions, n_skip = brainsp.read_mask("m.sm")`,
`brainsp.write_mask("m.sm", [(lo, hi, w, "label")])`,
`brainsp.STANDARD_OPTICAL_MASK`.

## Command line

```
brainsp fit spec/*.spec [--settings s.yaml] [--set name=value ...] [--corrections c.csv] [-o out] [--device gpu]
brainsp cube c.fits --redshift 0.02 --wavelength-scale vacuum --sn 3 10 --fit-sn 3 [--mask m.sm] [--table t.csv] [--export run.py|--check]
brainsp plot out/g_summary.txt -o fit.png        |  brainsp plot mega.fits --map vrot_star -o v.png
brainsp plot mega.fits --diagnostic "BPT [N II]" -o bpt.png  |  brainsp plot mega.fits --export maps
brainsp init settings.yaml | run.py   brainsp check s.yaml   brainsp settings [NAME]
brainsp libraries [info NAME | install FOLDER]   brainsp examples   brainsp selftest [--quick]
brainsp gui   brainsp desktop   brainsp clear-cache
```

## Conventions that change numbers (get these right)

- **Wavelength scale** (`wavelength_scale`: `air`/`vacuum`) is required in
  `espop`/`nepop`/`photopop`. SDSS, MaNGA, DESI, LAMOST: vacuum; MUSE, CALIFA:
  air. Wrong ⇒ every gas velocity off by ~83 km/s, nothing else shows it.
- **Cube redshift is required**; blank used to fit at z = 0 (stars at the wrong
  velocity). For a rest-frame cube give 0.
- **Spectrum line fluxes** (`r.lines`, summary file): in units of the
  NORMALISED spectrum (continuum = 1 at λ0 = 5500 Å) × Å, and CORRECTED for the
  stellar A_V relative to λ0. `r.line_fluxes(units="input", observed=True)`
  gives physical observed fluxes. **Cube** `FLUX_M` maps are already observed,
  in the cube's units × Å (megacube convention, Riffel et al. 2023). Don't mix them uncorrected.
- Tied doublets: `[O III]_Doublet`, `[N II]_Doublet` = the strong line's
  flux (5007, 6583); members also listed by name at 0.33510 / 0.32739.
- `sigma`/`vd_min`/`Sigma_star` are OBSERVED dispersions (include the
  instrument–library LSF difference) unless `instrumental_resolution` is set;
  then `sigma_star`/`Sigma_star_c` are intrinsic. Gas dispersions are always
  observed.
- Masses (`Mini_tot`, `Mcor_tot`) are APPARENT (no distance): × flux_unit ×
  4πd² / 3.828e33 for M☉. Mass fractions exact. AGN components have light, no
  mass.
- `Mage_L` = light-weighted mean of log10(age/yr), not log of mean age.
- Individual population weights are degenerate (age–Z–dust); report averages
  or broad age-bin sums.
- Light fractions `x_j` are at λ0 (5500 Å) and include AGN; `mcor` over stars.
- Masks: `.sm`/`.gm` files (count line, then N `start end weight [label]`);
  only N lines read. Weight 0 = out, 2 = double. Applied as given in EVERY
  mode, spectra and cubes (gaps, chip breaks, bad columns). In espop/nepop/
  photopop do NOT mask lines you want fitted: a line with < half its ±2σ
  pixels unmasked is dropped (warning; absent from summary/`r.lines`/maps;
  BPT/WHAN then impossible) rather than given an arbitrary flux.
- Cube `mask_hdu` is read as MaNGA bitmask: only bit 10 (1024) = bad.
  For MUSE DQ / CALIFA BADPIX, rebuild as 1024 or use `mask_hdu=None`.
- S/N masks keep spaxels with S/N **>** threshold (strict).
- `chi2` = χ²/N_eff (~0.6–0.7 on resampled noise is
  normal); cube `CHI2RED` = χ²/(N_eff − n_par).
- Default fitting range 3700–6900 Å; BasesGM covers 3540–6996 Å and cannot do
  `nepop`/`photopop` (no ionising UV). `brainsp libraries info X` →
  `reaches_lyman`.
- `velocity_range` must contain the galaxy's velocity in the spectrum's
  frame (observed-frame spectrum without z removed: ≈ cz).

## Performance facts

- First fit compiles (seconds); later fits of the same shape reuse it. Keep
  range, templates and mode fixed across a batch. Cache: `~/.cache/brain/jax`.
- Warm single spectrum: GPU ~0.5 s (spop), ~1 s (espop); CPU ~1.4 / 2.4 s.
- CPU: cubes and long lists of spectra run on worker processes, one thread
  each (`cpu_workers: auto` = cores allowed − 1, ≤ free RAM/1.2 GB). One
  process cannot use many cores for this. GPU: batches of spaxels.

## Libraries

`brainsp.libraries.available()`, `.info(name)`, `.install(folder)`; a
library = folder with `CATALOGUE.txt` (`AGE_YR Z FILENAME SHORT_NAME MSTARS
KIND`), templates two columns (Å, flux). Search: path,
`$BRAINSP_LIBRARY_PATH`, `~/.brainsp/libraries`, package. Select with
`base_folder="NAME"`, `ages=[...]`, `metallicities=[...]`.

## When something fails

- `brainsp check s.yaml` / `Settings.validate()` / `CubePipeline.validate()`
  list every problem at once with the fix.
- "Fitting 0 pixels": flag column inverted (0 must mean good).
- Flat model past ~7000 Å: outside BasesGM; narrow `wavelength_max`.
- Velocity wrong: widen `velocity_range` or remove the redshift.
- Interface failures append the full message to `brain_error.log` in the output folder.
- Verify against mocks: `brainsp.mock.make_spectrum(...)` with the user's S/N.
