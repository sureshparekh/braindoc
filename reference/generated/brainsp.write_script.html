write_script#

brainsp.write_script(path, kind='spectrum', settings=None, spectra=(), pipeline=None, device='auto', **pipeline_options)[source]#

Write a run as one Python file.

Parameters:
pathstr

The .py file to write.

kind{“spectrum”, “cube”}
settingsSettings, dict or str, optional
spectralist of str or (str, dict)

For kind="spectrum": the spectra, optionally with their own settings.

pipelineCubePipeline, optional

For kind="cube"; or give its options as keyword arguments (cubes=, redshift= …).

devicestr
Returns:
str

path.

Examples

>>> brainsp.write_script("run_spectra.py", spectra=["a.spec", "b.spec"],
...                      settings=brainsp.Settings(nebular_mode="espop"))
>>> brainsp.write_script("run_cube.py", kind="cube", cubes=["c.fits"],
...                      redshift=0.02)
