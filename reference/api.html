ReferencePython API

Python API#

Every public name of brainsp, generated from the code’s own documentation. Each entry links to a page with its full signature, every parameter and return value, and examples. The Python library explains how they fit together.

Fitting#

fit_spectrum

Fit one spectrum.

fit_spectra

Fit several spectra, each with its own pre-fit corrections if given.

fit_cube

Fit one datacube and open the megacube it produces.

CubePipeline

A datacube run: the preparation stages, the fit, and its outputs.

Settings

Every BRAIN setting, with its default, as a dictionary.

set_device

Choose the processor BRAIN fits on, before the first fit.

Reading results#

read_result

Read a fit already on disk.

FitResult

The result of fitting one spectrum, read from the files BRAIN wrote.

read_megacube

Open a megacube BRAIN wrote.

Megacube

A BRAIN megacube, read once, with its maps named and grouped.

read_corrections_table

Per-spectrum pre-fit corrections from a CSV file.

Masks, scripts and checks#

read_mask

The regions of a wavelength mask file, as [(start, end, weight, label)].

write_mask

Write regions as a .sm mask file: the count, then one per line.

write_script

Write a run as one Python file.

selftest

Run the self-test.

brainsp.STANDARD_OPTICAL_MASK is the list of the eleven standard optical windows, (start, end) in Å (Wavelength masks).

Modules#

Module

What it holds

brainsp.plots

every figure: spectra, star formation histories, maps, spaxels, diagnostics, map export

brainsp.libraries

list, inspect and install template libraries; which can run nespop

brainsp.mock

mock spectra and datacubes with known answers

brainsp.corrections

the redshift and Galactic reddening, on arrays

brainsp.megacube

the megacube reader and the diagnostic curves and classes

brainsp.reddening_laws

the extinction laws

brainsp.scripts

a run as one Python file

The machinery#

For developers and for running BRAIN at scale: how BRAIN sees the machine, deals work to CPU workers and GPU slots, and computes the uncertainties.

Module

What it holds

brainsp.machine

the machine’s cores and GPUs, and the GPU lane rule

brainsp.scheduler

GPU slots: several cubes at once, one cube over several GPUs

brainsp.cpu_pool

the worker processes behind every stage of a fit

brainsp.uncertainties

the formal covariance and the bootstrap
