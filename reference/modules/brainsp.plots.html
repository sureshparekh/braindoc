brainsp.plots#

Figures from code: every plot the desktop interface draws, written to a file.

Each function draws on a matplotlib Figure (no display needed) and, when given a path, writes it there; the suffix picks the format (.png, .pdf, .svg, .jpg). Each returns the Figure, so it can be changed further before it is saved, and a function given ax= draws into an existing axes instead, for a figure of your own.

For a single spectrum (from brainsp.fit_spectrum()):

  • spectrum_fit() – the standard BRAIN figure: data, model, stellar and

emission components, residuals and the headline numbers.

  • spectrum() – the data and model on one axes, optionally zoomed.

  • sfh() – the star-formation history, light- or mass-weighted.

For a datacube (from brainsp.fit_cube() or brainsp.read_megacube()):

  • map() – one map, with the unfitted spaxels grey and hatched.

  • maps() – several maps on one page.

  • export_maps() – maps to files: images for a paper and FITS with the

cube's sky coordinates and a mask saying which spaxels are measurements.

  • spaxel() – one spaxel’s spectrum, model and emission lines.

  • sfh() – one spaxel’s star-formation history (y=, x=).

  • diagnostic() – the BPT [N II], BPT [S II] or WHAN diagram, the

spaxels coloured by class, with the dividing curves.

Figures are drawn for print: white ground, black text, a stated unit on every axis, perceptually uniform colour maps.

brainsp.plots.sfh(source, path=None, *, y=None, x=None, kind='both', ax=None, cumulative=False)[source]#

The star-formation history: the fraction of light or mass in each age.

Fractions at the same age (different metallicities) are summed; light fractions are at the normalisation wavelength, mass fractions are of the present stellar mass.

Parameters:
sourceFitResult, str or Megacube

A spectrum fit, or a megacube with y and x naming a spaxel.

pathstr, optional
y, xint, optional

The spaxel, for a megacube.

kind{“light”, “mass”, “both”}
axmatplotlib.axes.Axes, optional

Draw into these axes (kind must then be "light" or "mass").

brainsp.plots.export_maps(cube, folder, names=None, *, formats=('png', 'fits'), cmap='viridis', scale='clip')[source]#

Write maps to files, one per map and format.

Images (png, pdf) are drawn for print. fits writes the map with the cube’s sky coordinates and a TRUST extension whose bits say why a spaxel is not a measurement (not fitted, no value), so the file can be read without the megacube.

Parameters:

folderstr

Maps to write; every map in the megacube by default.

Any of "png", "pdf", "svg", "fits".
