brainsp.libraries#

Template libraries: where they are, what is in them, how to add one.

A library is a folder of single-stellar-population (SSP) spectra with a CATALOGUE.txt that lists them, one per line:

# AGE_YR      Z         FILENAME                 SHORT_NAME   MSTARS   KIND
1.0e+06       0.019     bc03_z019_t1e6.dat       t1e6_z019    1.0      ssp

Each template file holds two columns, wavelength in Angstrom (rest frame, air or vacuum as the library states) and flux per unit wavelength for the population, normalised as the library normalises it. MSTARS is the fraction of the initial mass still in stars (and remnants) at that age, used to turn light fractions into stellar masses; KIND is ssp for a stellar population and powerlaw for a featureless component such as an AGN continuum. Lines starting with # are comments.

Libraries are looked up by name, in this order:

  1. a folder path given directly (absolute, or relative to the working

directory);

  1. every folder in the BRAINSP_LIBRARY_PATH environment variable

(separated by ``:`` on Linux and macOS, ``;`` on Windows);

  1. ~/.brainsp/libraries (or $BRAINSP_HOME/libraries), where

:func:`install` puts libraries added after installation;

  1. the libraries shipped inside the package (BasesGM, M13 and

``BC03``, the library the nebular mode nespop is validated with).

So a library added later, however large, does not have to live inside the package: install it once with install(), or point BRAINSP_LIBRARY_PATH at the folder that holds it, and refer to it by its folder name everywhere (base_folder="MILES" in the settings, the Library menu in the interface).

The AGN folder shipped with the package is not a library: it holds the seven featureless continua that include_power_law adds to a library, and it is never offered as one. A library can carry its own AGN set instead, in an AGN sub-folder with a CATALOGUE.txt of the same layout (KIND powerlaw, blackbody, …): include_power_law then adds that set, and not the package’s seven (agn_folder()). M13, for example, ships power laws and hot-dust blackbodies built for it.

brainsp.libraries.nebular_status(name_or_folder)[source]#

Whether a library can run the nebular mode, nespop.

Returns:
dict

status: "validated" (it reaches the Lyman limit and nespop has been validated with it), "unvalidated" (it reaches the Lyman limit; nespop runs, untested with it) or "unable" (it does not: its nebular continuum would be identically zero); name; reason, a sentence saying which and why.

brainsp.libraries.agn_folder(library=None)[source]#

The AGN templates include_power_law adds to library.

The library’s own set, <library>/AGN/CATALOGUE.txt, when it has one; otherwise the seven continua shipped with the package. With no library given, the package’s set.

brainsp.libraries.search_path()[source]#

The folders searched for libraries, first match winning.

Returns:
list of str

BRAINSP_LIBRARY_PATH entries, then the per-user library folder, then the package’s own.

brainsp.libraries.available()[source]#

The names of every library that can be used, in search order.

Returns:
list of str

Folder names, e.g. ["BasesGM"]. A name found in two places is listed once, for the place that wins.

Examples

>>> import brainsp
>>> brainsp.libraries.available()
['BasesGM', 'M13']
brainsp.libraries.path(name_or_folder='BasesGM')[source]#

The folder of a library, from its name or a path to it.

Parameters:
name_or_folderstr

A library name such as "BasesGM" (a trailing / is ignored), or a path to a folder holding a CATALOGUE.txt.

Returns:
str

Absolute path of the library folder.

Raises:
SystemExit

When no folder of that name holds a catalogue. The message lists the libraries that are available and where they were looked for.

brainsp.libraries.info(name_or_folder='BasesGM')[source]#

What a library holds.

Parameters:
name_or_folderstr

Library name or folder.

Returns:
dict

folder; n_ssp; ages_yr and metallicities (sorted); extra (names of non-SSP components the library carries); agn (the components include_power_law adds) and agn_folder (where they are: the library’s own AGN set, or the package’s); wavelength_min and wavelength_max in Angstrom (the range every template covers); reaches_lyman (True when every template extends below the Lyman limit at 911.76 A, which the nebular continuum mode nespop needs).
