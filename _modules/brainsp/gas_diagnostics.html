Source code for brainsp.gas_diagnostics

"""
BRAIN — nebular diagnostics measured from the fitted emission lines.

Two things BRAIN measures per spectrum that were previously taken from config:

  1. Electron density from the [S II] 6716/6731 doublet ratio, and electron
     temperature from the [O III] (4959+5007)/4363 ratio. BRAIN measures both
     on the fly and only falls back to standard conditions (100 cm^-3, 10^4 K)
     when the lines are too weak to be trusted.

  2. Spectral classification on the BPT diagram. This is REPORTED, not acted
     on. It is a diagnostic, and a continuum-model-dependent one: Hbeta sits
     in deep stellar absorption, so its measured flux depends on the continuum
     model, and both BPT ratios use it. The same spectrum and the same library
     can change class when only the nebular treatment changes.

Both are guarded: a diagnostic that cannot be measured reliably returns the
fallback and says so, rather than returning a confident wrong number.

What gates the nebular work is Hbeta DETECTABILITY, not BPT class. If Hbeta
cannot be measured then the Balmer decrement cannot be formed, so the nebular
extinction and everything derived from it must not be attempted. That gate
lives in brainv1 where the line fluxes are, and it is applied once. An earlier
version had a class-based downgrade here AND a Balmer-detection guard in
brainv1 that silently overrode it, so photopop mode ran on some spectra and not
others for reasons that had nothing to do with either rule.
"""

import logging
import numpy as np

logger = logging.getLogger("NEWBRAIN")

TE_DEFAULT = 1.0e4
NE_DEFAULT = 1.0e2

SII_RATIO_MIN = 0.45
SII_RATIO_MAX = 1.42

MIN_LINE_FLUX = 1e-6


def _flux(lines, *names):
    """
    The flux of the first of `names` that the fitted lines provide.

    `names` are ALTERNATIVE spellings of one quantity, not things to add up.
    Resolution stops at the first one that matches anything, because the
    fitted-line dict carries both a full catalogue name and a species alias
    for hydrogen, and treating the alternatives as cumulative counted Halpha
    and Hbeta twice each. That happened to cancel in the BPT ratios, which is
    why it survived.

    An exact key wins outright. Failing that, every entry of that species is
    summed, so asking for a species that the catalogue splits into components
    returns the whole of it rather than whichever component came first.

    The alternatives after a doublet name are the doublet's ratio-1.0
    component, which is the entry precompile_line_table leaves behind when
    the other component falls off the wavelength grid. A doublet column is
    built with ratios relative to that component, so its weight already IS
    that component's flux, and the survivor is renormalised to 1.0 for the
    same reason: the two spellings are then on one scale and no branching
    ratio has to be remembered at the point of use.

    The weaker component is deliberately not offered as an alternative. If
    [O III] 5007 is off the grid and only 4959 survives, its flux is about a
    third of the quantity a BPT diagram wants, and reporting 'undetermined'
    is the honest answer rather than a class derived from a number three
    times too small.
    """
    from brainsp.emission_lines import species_of
    for want in names:
        if want in lines:
            return float(lines[want]), True
        same_species = [float(v) for k, v in lines.items()
                        if species_of(k) == want]
        if same_species:
            return sum(same_species), True
    return 0.0, False

def electron_density(lines, Te=TE_DEFAULT):
    """
    Density from the [S II] doublet, via the Proxauf, Ottl & Kimeswenger
    (2014) calibration.

    Returns (n_e, ok). `ok` is False when the lines are too weak or the ratio
    sits outside the density-sensitive window, in which case n_e is the
    default rather than an extrapolation.
    """
    f16, ok16 = _flux(lines, '[S II]_6716', '[SII]_6716')
    f31, ok31 = _flux(lines, '[S II]_6731', '[SII]_6731')
    if not (ok16 and ok31) or f16 < MIN_LINE_FLUX or f31 < MIN_LINE_FLUX:
        return NE_DEFAULT, False

    R = f16 / f31
    if not (SII_RATIO_MIN < R < SII_RATIO_MAX):
        return NE_DEFAULT, False

    log_ne = (0.0543 * np.tan(-3.0553 * R + 2.8506)
              + 6.98 - 10.6905 * R + 9.9186 * R ** 2 - 3.5442 * R ** 3)
    ne = float(10.0 ** log_ne)
    ne *= np.sqrt(Te / 1.0e4)
    if not np.isfinite(ne) or not (1.0 <= ne <= 1.0e6):
        return NE_DEFAULT, False
    return ne, True

def electron_temperature(lines, ne=NE_DEFAULT):
    """
    Temperature from the [O III] auroral-to-nebular ratio (Osterbrock &
    Ferland 2006, Eq. 5.4), solved iteratively because the collisional
    de-excitation correction itself depends on T_e.

    THE NUMERATOR IS THE NEBULAR SUM, F(4959) + F(5007), and a fitted
    doublet weight is not that. The [O III] column is built with its
    components' ratios relative to 5007, so its weight is F(5007) alone,
    which is what the BPT diagram wants and what the line table reports.
    doublet_nebular_sum_factor supplies the missing F(4959), at the
    branching ratio the design matrix itself used, so the diagnostic and
    the model cannot drift apart.

    The error this repairs was one-sided. Using F(5007) where
    F(4959) + F(5007) belongs makes R low by a factor 1.33510, and
    T_e = 3.29e4 / ln(R corr / 7.90) RISES as R falls, so every measured
    temperature came out too hot, and by more the hotter the gas: a gas at
    10^4 K was reported at 10963 K and one at 2 x 10^4 K at 24263 K, high
    by 9.6 and 21.3 per cent of the right answer. It does
    not stop at a reported number. measure_conditions feeds T_e back into
    the density, and brainv1 rebuilds the NebularModel and refits whenever
    the measured conditions move by more than the tolerance there, so in
    nepop and photopop this sets the nebular continuum itself.

    The R > 8 gate reads as a floor on a nebular-sum ratio now, which is
    how Eq. 5.4 is written; R is 1.33510 times larger than before, so
    ratios between 5.99 and 8.00 in the old units pass it that did not.
    Nothing is reported from that, because R that small implies T_e above
    10^5 K and the 5000-30000 K window below rejects it. The window is
    where the correction changes an answer: a spectrum whose old T_e fell
    between 30000 and 40735 K was discarded as unphysically hot and is now
    measured, and one whose old T_e fell between 5000 and 5230 K was
    measured and is now discarded as too cold.

    [O III] 4363 is intrinsically faint, so this fails far more often than it
    succeeds. Returns (T_e, ok).
    """
    from brainsp.emission_lines import doublet_nebular_sum_factor

    f43, ok43 = _flux(lines, '[O III]_4363', '[OIII]_4363')
    f_5007, ok5007 = _flux(lines, '[O III]_Doublet', '[OIII]_Doublet',
                           '[O III]_5007', '[OIII]_5007')
    if not (ok43 and ok5007) or f43 < MIN_LINE_FLUX or f_5007 < MIN_LINE_FLUX:
        return TE_DEFAULT, False

    f_neb = f_5007 * doublet_nebular_sum_factor('[O III]_Doublet')
    R = f_neb / f43
    if R <= 8.0:
        return TE_DEFAULT, False

    Te = TE_DEFAULT
    for _ in range(30):
        corr = 1.0 + 4.5e-4 * ne / np.sqrt(max(Te, 1.0))
        arg = R * corr / 7.90
        if arg <= 1.0:
            return TE_DEFAULT, False
        Te_new = 3.29e4 / np.log(arg)
        if not np.isfinite(Te_new):
            return TE_DEFAULT, False
        if abs(Te_new - Te) / max(Te, 1.0) < 1e-4:
            Te = Te_new
            break
        Te = Te_new

    if not (5.0e3 <= Te <= 3.0e4):
        return TE_DEFAULT, False
    return float(Te), True

def measure_conditions(lines, verbose=True):
    """
    Measure n_e and T_e together, iterating once because each depends on the
    other. Returns a dict with the values and whether each was measured.
    """
    ne, ne_ok = electron_density(lines)
    Te, Te_ok = electron_temperature(lines, ne)
    if Te_ok:
        ne, ne_ok = electron_density(lines, Te)

    if verbose:
        logger.info(
            f"   Gas conditions: n_e = {ne:.0f} cm^-3 "
            f"({'measured from [S II]' if ne_ok else 'default, [S II] unusable'}), "
            f"T_e = {Te:.0f} K "
            f"({'measured from [O III]' if Te_ok else 'default, [O III] 4363 unusable'})")
    return {'ne': ne, 'Te': Te, 'ne_measured': ne_ok, 'Te_measured': Te_ok}

def classify_bpt(lines, min_snr_flux=MIN_LINE_FLUX):
    """
    Classify on the [O III]/Hb vs [N II]/Ha diagram.

    Demarcations:
      Kauffmann et al. (2003)  pure star-forming
      Kewley et al. (2001)     maximum starburst
      Schawinski et al. (2007) Seyfert / LINER split above Kewley

    Returns (label, info) with label one of
    'SF', 'composite', 'Seyfert', 'LINER', 'undetermined'.

    The label is a report, never a gate. It depends on the continuum model
    through Hbeta, which both ratios use and which sits in deep stellar
    absorption, so changing only the nebular treatment can change the class of
    an unchanged spectrum.
    """
    ha, oka = _flux(lines, 'Halpha_6563', 'Halpha')
    hb, okb = _flux(lines, 'Hbeta_4861', 'Hbeta')
    n2, okn = _flux(lines, '[N II]_Doublet', '[NII]_Doublet',
                    '[N II]_6583', '[NII]_6583')
    o3, oko = _flux(lines, '[O III]_Doublet', '[OIII]_Doublet',
                    '[O III]_5007', '[OIII]_5007')

    info = {'Halpha': ha, 'Hbeta': hb, 'NII': n2, 'OIII': o3}
    if not all((oka, okb, okn, oko)) or min(ha, hb, n2, o3) < min_snr_flux:
        info['reason'] = 'one or more BPT lines undetected'
        return 'undetermined', info

    x = np.log10(n2 / ha)
    y = np.log10(o3 / hb)
    info['log_NII_Ha'], info['log_OIII_Hb'] = float(x), float(y)

    kauff = 0.61 / (x - 0.05) + 1.30 if x < 0.05 else -np.inf
    kewley = 0.61 / (x - 0.47) + 1.19 if x < 0.47 else -np.inf

    if y < kauff:
        label = 'SF'
    elif y < kewley:
        label = 'composite'
    else:
        label = 'Seyfert' if y > 1.05 * x + 0.45 else 'LINER'
    info['reason'] = f'log[NII]/Ha={x:.2f}, log[OIII]/Hb={y:.2f}'
    return label, info

def nebular_constrained(wavelength, inv_sigma, flux, min_snr=2.0,
                        min_pixels=20, verbose=True):
    """
    Check whether the fit can actually distinguish a nebular continuum.

    The nebular continuum is smooth and rises to the blue, which makes it
    nearly degenerate with dust. What breaks the degeneracy is the Balmer
    discontinuity at 3646 A: recombination to n=2 emits only at shorter
    wavelengths, so the nebular continuum is elevated blueward of the jump and
    drops sharply across it — a feature no reddening law or stellar template
    can mimic.

    If that region is outside the fitted range, or too noisy to measure, then
    a freely fitted nebular component is unconstrained and will silently trade
    against A_V. Measured on the reference spectrum: S/N ~ 0.5 below the jump
    against ~5.5 in the red, and the fit duly ran A_V to its lower bound.

    Returns (ok, info).
    """
    wl = np.asarray(wavelength)
    iv = np.asarray(inv_sigma)
    fx = np.asarray(flux)

    info = {'jump_in_range': bool(wl[0] <= BALMER_JUMP <= wl[-1])}
    if not info['jump_in_range']:
        info['reason'] = (f"Balmer jump ({BALMER_JUMP:.0f} A) lies outside the "
                          f"fitted range {wl[0]:.0f}-{wl[-1]:.0f} A")
        if verbose:
            logger.warning(f"   Nebular continuum is weakly constrained: "
                           f"{info['reason']}. It may trade against A_V.")
        return False, info

    win = (wl > BALMER_JUMP - 120.0) & (wl < BALMER_JUMP + 120.0) & (iv > 0)
    n = int(np.sum(win))
    info['pixels'] = n
    if n < min_pixels:
        info['reason'] = f"only {n} usable pixels around the Balmer jump"
        if verbose:
            logger.warning(f"   Nebular continuum is weakly constrained: "
                           f"{info['reason']}.")
        return False, info

    snr = float(np.median(np.abs(fx[win]) * iv[win]))
    info['snr'] = snr
    if snr < min_snr:
        info['reason'] = (f"S/N ~ {snr:.1f} around the Balmer jump "
                          f"(need >= {min_snr:.0f})")
        if verbose:
            logger.warning(f"   Nebular continuum is weakly constrained: "
                           f"{info['reason']}. Its weight may absorb dust "
                           f"rather than real nebular light.")
        return False, info

    if verbose:
        logger.info(f"   Balmer jump measurable (S/N ~ {snr:.1f}) — "
                    f"nebular continuum is constrained")
    return True, info

def gas_kinematics_report(group_labels, group_kinematics, line_names,
                          line_group_positions, line_fluxes, line_wavelengths,
                          lower_bound, upper_bound, lsf_info=None):
    """
    Turn each kinematic group's fitted sigma and v0 into something quotable,
    or say why it is not.

    The stellar side has refused to quote a bound since the line-spread
    function work: instrumental_lsf.dispersion_report writes '<47.55' with a
    leading '<' and the word UPPER LIMIT rather than a number a reader could
    mistake for a measurement, and writes 'unknown' when the instrument is not
    known. The gas side had nothing, and a sigma_gas sitting exactly on its
    lower bound printed as a plain number. This is that same refusal, for the
    gas, and it deliberately reads the same way; on_bound is imported rather
    than copied so the two cannot come to disagree about what a rail is.

    A group's dispersion is not quotable for either of two reasons.

    ON A BOUND
        sigma_gas came back on an end of gas_dispersion_range. On the lower
        end the fit wanted a narrower line than it was allowed, so the value
        is an UPPER LIMIT and is written '<'; on the upper end it wanted a
        broader one, so it is a LOWER LIMIT and is written '>'. Neither is a
        width. This is not hypothetical: until the pixel-width floor was
        removed, both groups of the reference spectrum sat on 58.39 km/s and
        printed as measurements.

    NO LINE DETECTED
        The kinematics of a group are carried entirely by the lines in it. The
        non-negative solve puts a line at EXACTLY zero when no non-negative
        amplitude improves the fit, which is a statement and not a rounding,
        and a group whose lines all come back at zero has a flat likelihood in
        both sigma and v0: the optimiser returns whatever it started from or
        wandered to, converged, with nothing to say so. On the reference
        spectrum two of the high-ionisation group's four lines ([Ne III] 3869
        and the [O III] doublet) fit at exactly zero, so that group's
        kinematics rest on two lines at most; a spectrum where all four go to
        zero would report two numbers that mean nothing at all. The count of
        lines carrying flux is therefore reported alongside every group, and a
        group with none is refused outright, v0 as well as sigma.

    WHAT THE NUMBER IS A DISPERSION OF

    sigma_gas is OBSERVED. The instrumental line-spread function is still in
    it; nothing is deconvolved from the emission line, which is why the label
    written beside it states the convention rather than leaving it to be
    assumed. sigma_star in the same summary is INTRINSIC, the instrument taken
    out in quadrature, so the two numbers are not comparable as printed and
    the file has to say which is which.

    sigma_inst is reported next to sigma_gas, per group, whenever
    'instrumental_resolution' is set, and 'unknown' when it is not. That
    follows Westfall et al. (2019), who report the observed and the
    instrumental dispersion as separate maps and deliberately do not do the
    subtraction (Section 7.3: "we do not provide the corrected
    velocity dispersion ... We leave it to the user"). Nothing here is
    clipped, floored or called zero when sigma_gas comes out below sigma_inst,
    which over the MaNGA line-spread function of 68.0-83.5 km/s is where every
    sigma_gas BRAIN currently reports lands: Westfall Section 7.6.3 is
    explicit that such a measurement is neither equivalent to nor a valid
    measurement of sigma = 0, and recommends carrying the negative sigma^2
    rather than clipping it. Both numbers are given so that the reader can do
    that arithmetic, and neither is done for them.

    Parameters
    ----------
    group_labels : list
        The groups' labels, in the POSITION order the fitted parameter vector
        lays them out. What the user called a group and where it sits in that
        vector are different things; see emission_lines.group_positions.
    group_kinematics : dict
        {label: (sigma_gas, v0_gas)} in km/s, as the fit returned them.
    line_names : list of str
        One name per fitted gas column.
    line_group_positions : sequence of int
        The POSITION of each column's group, one per column.
    line_fluxes : sequence of float
        The fitted weight of each column, which is its flux.
    line_wavelengths : sequence of float
        One wavelength per column, in Angstrom, for looking up the instrument.
    lower_bound, upper_bound : float
        gas_dispersion_range, in km/s.
    lsf_info : dict or None
        What instrumental_lsf.prepare_templates recorded about the data's
        line-spread function. None, or a run with no 'instrumental_resolution',
        gives sigma_inst = None and the word 'unknown' in the output.

    Returns
    -------
    list of dict, one per group, in the same position order as group_labels.
    """
    from brainsp.instrumental_lsf import on_bound, instrumental_dispersion_at

    names = list(line_names)
    positions = np.asarray(line_group_positions, dtype=int)
    fluxes = np.asarray(line_fluxes, dtype=np.float64)
    wavelengths = np.asarray(line_wavelengths, dtype=np.float64)

    sigma_inst_per_line = instrumental_dispersion_at(lsf_info, wavelengths)

    low = float(lower_bound)
    high = float(upper_bound)

    report = []
    for position, label in enumerate(group_labels):
        sigma, v0 = group_kinematics.get(label, (float("nan"),) * 2)
        sigma, v0 = float(sigma), float(v0)

        member = positions == position
        detected = member & (fluxes > 0.0)
        n_lines = int(np.sum(member))
        n_detected = int(np.sum(detected))

        railed_low, railed_high = on_bound(sigma, low, high)

        sigma_inst = None
        if sigma_inst_per_line is not None and n_lines:
            weight = np.where(detected, fluxes, 0.0)
            if weight.sum() <= 0:
                weight = member.astype(np.float64)
            sigma_inst = float(np.sum(weight * sigma_inst_per_line)
                               / np.sum(weight))

        entry = {
            "label": label,
            "sigma_obs": sigma,
            "v0": v0,
            "n_lines": n_lines,
            "n_detected": n_detected,
            "detected_names": [n for n, d in zip(names, detected) if d],
            "flux_total": float(np.sum(fluxes[member])) if n_lines else 0.0,
            "railed_low": bool(railed_low),
            "railed_high": bool(railed_high),
            "sigma_inst": sigma_inst,
            "quotable": False,
            "status": "measured",
            "reason": None,
        }

        if n_detected == 0:
            entry["status"] = "UNCONSTRAINED"
            entry["reason"] = (
                f"group {label!r} has no detected line: all {n_lines} of its "
                f"lines came back at exactly zero flux from the non-negative "
                f"solve, so nothing in the spectrum constrains either its "
                f"dispersion or its velocity. The optimiser returned "
                f"sigma_gas {sigma:.2f} km/s and v0_gas {v0:.2f} km/s and "
                f"reported success; both are artefacts of where the search "
                f"started, not measurements, and neither is written as a "
                f"number.")
        elif railed_low:
            entry["status"] = "UPPER LIMIT"
            entry["reason"] = (
                f"group {label!r} came back on the lower bound of "
                f"gas_dispersion_range ({low:.2f} km/s), so it is a bound and "
                f"not a measurement: the fit wanted a narrower line than it "
                f"was allowed. sigma_gas < {low:.2f} km/s is all this "
                f"spectrum says. Lower the first number of "
                f"gas_dispersion_range and re-run.")
        elif railed_high:
            entry["status"] = "LOWER LIMIT"
            entry["reason"] = (
                f"group {label!r} came back on the upper bound of "
                f"gas_dispersion_range ({high:.2f} km/s), so it is a bound "
                f"and not a measurement: the fit wanted a broader line than "
                f"it was allowed. sigma_gas > {high:.2f} km/s is all this "
                f"spectrum says. Raise the second number of "
                f"gas_dispersion_range and re-run, and check first that the "
                f"group is not absorbing something that is not a line.")
        else:
            entry["quotable"] = True

        if entry["quotable"] and n_detected < n_lines:
            entry["reason"] = (
                f"group {label!r} is fitted with {n_lines} lines and "
                f"{n_detected} of them carry flux; the rest came back at "
                f"exactly zero and contribute nothing to its kinematics.")

        report.append(entry)

    return report

def gas_dispersion_text(entry):
    """
    The token a summary or a log line prints in place of a gas dispersion.

    A quotable dispersion is the number. A dispersion on the lower bound is
    written '<value', on the upper bound '>value', and a group with no
    detected line prints the word 'unconstrained' and no number at all --
    exactly as instrumental_lsf writes '<47.55' and 'unknown' for the stellar
    side, so that the two blocks of one summary file read alike. The value the
    optimiser returned for an unconstrained group is not lost; it is in the
    reason text, where it cannot be mistaken for a result.
    """
    if entry["status"] == "UNCONSTRAINED":
        return "unconstrained"
    if entry["railed_low"]:
        return f"<{entry['sigma_obs']:.2f}"
    if entry["railed_high"]:
        return f">{entry['sigma_obs']:.2f}"
    return f"{entry['sigma_obs']:.2f}"

def gas_velocity_text(entry):
    """
    The same, for the group's velocity.

    A velocity is not bounded in the way a dispersion is -- a fit that reaches
    the end of gas_velocity_range has a different problem, and v0_star already
    reports its own -- so the only refusal here is the group with no detected
    line, whose velocity is as unconstrained as its width.
    """
    if entry["status"] == "UNCONSTRAINED":
        return "unconstrained"
    return f"{entry['v0']:.2f}"
