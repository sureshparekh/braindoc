Source code for brainsp.emission_lines

"""
Tied doublets, kinematic groups, and the Gaussian design matrix, with
per-group velocity and dispersion for the joint fit.

The wavelengths, the species table and the default kinematic groups are NOT
here. They live in line_catalogue, which imports numpy and nothing else, so
the settings validator and the desktop interface can ask what lines exist
without starting a JAX backend in the process that draws the menus. This
module imports JAX and is therefore the wrong place for pure data.

The names imported at the top are re-exported rather than redefined, so
`from emission_lines import LINE_SPECIES` keeps meaning exactly what it
meant. They are one table with two import paths, not two tables. New code
should read them from line_catalogue, which costs no JAX backend.

Nothing here derives meaning from the shape of a catalogue name. Every
entry's species is declared in LINE_SPECIES, every doublet names its
components rather than repeating their wavelengths, and group membership is
looked up by species rather than matched as a string prefix. That is not
tidiness. Each of the three couplings this replaces failed silently:

  - Kinematic groups were assigned by name.startswith(prefix), and "He I" is
    a prefix of "He II", so He II_4686 -- a high-ionisation line -- was
    placed in the low-ionisation group. Measured, not hypothetical.
  - Free lines were removed from the catalogue when a tied doublet already
    covered them by testing the wavelength for membership of a set of
    floats. Exact float equality held only while both numbers were
    whole-Angstrom literals written twice. Store the doublet's wavelength to
    more decimals than the line's and the deduplication stops working, the
    same wavelength gets two columns, the gas block goes rank-deficient, and
    a non-negative solver splits the flux between them at an arbitrary
    vertex without complaining.
  - Line fluxes were extracted by substring, returning the first name that
    contained the key. "[S II]" returns 6716 and silently discards 6731,
    which is half the density diagnostic; "[O III]" returns the 4363
    auroral line rather than the doublet; "He I" returns He II. It happens
    not to misfire today only because the two keys in use, Halpha and
    Hbeta, are unambiguous in the shipped catalogue.

Every entry point that produces wavelengths takes the observed spectrum's
wavelength scale as a required argument. There is no default, because a
default is a guess: a wrong guess moves every line by about 83 km/s, which
the fitted gas velocity absorbs almost entirely, so the fit converges and
nothing in the output looks wrong. See line_catalogue for the conversion
and brain_settings for the refusal.
"""

import logging

import numpy as np
import jax
import jax.numpy as jnp
from functools import partial

from brainsp.line_catalogue import (
    DEFAULT_GROUP_SPECIES,
    LINE_SPECIES,

    require_scale,
    species_of,
)

logger = logging.getLogger("NEWBRAIN")

C_KMS = 299792.458

TIED_DOUBLETS = {
    '[O III]_Doublet': [('[O III]_4959', 0.33510), ('[O III]_5007', 1.0)],
    '[N II]_Doublet': [('[N II]_6548', 0.32739), ('[N II]_6583', 1.0)],
    '[S III]_Doublet': [('[S III]_9069', 0.40506), ('[S III]_9531', 1.0)],
}
"""
Pairs whose relative flux is fixed by atomic physics rather than by the fit.

Every pair here is the 1D2 - 3P1 and 1D2 - 3P2 transition out of ONE upper
level, so the intensity ratio is A(1D2-3P1) E(1D2-3P1) divided by
A(1D2-3P2) E(1D2-3P2) and nothing else. It is EXACTLY independent of
electron temperature, electron density, ionisation parameter and
abundance: both photons leave the same level, so whatever sets how often
that level is populated cancels identically. There is no modelling choice
to make and no ratio to fit, only the right number, and a number rounded
to two figures is simply a wrong one.

The weak component's ratio is quoted relative to the strong component,
which carries 1.0, because a doublet column is the ratio-weighted sum of
area-normalised profiles: the fitted weight is then the flux of the
ratio-1.0 line, which is the quantity the BPT calibrations and the line
table report. doublet_nebular_sum_factor is the one conversion to the sum
over both components, for the one diagnostic that wants a sum.

[O III] 4959/5007 and [N II] 6548/6583 are the relativistically corrected
values of Storey & Zeippen (2000), MNRAS 312, 813, Tables 3 and 4, whose
A-value ratios become 0.33510 and 0.32739 once scaled by the ratio of
transition energies. THE CITATION IS EXPLICIT BECAUSE OLDER ATOMIC DATA
DIFFER: the Froese Fischer et al. (2004) data for N II give 0.3399, 3.8 per
cent away from the value here, and a comparison against results built on
them will show that difference in [N II]; it is not a BRAIN defect.

[S III] 9069/9531 is NOT from Storey & Zeippen, whose calculation covers
the carbon and oxygen sequences to Z = 12 only; S III is the 3p2 analogue
and is outside it. 0.40506 is Froese Fischer, Tachiev & Irimia (2006),
ADNDT 92, 607, as compiled by Podobedova, Kelleher & Wiese (2009). The
0.41 it replaces corresponds to no published calculation: the same data
sets give 0.40322 (Mendoza & Zeippen 1982) and 0.39435 (Tayal, Zatsarinny
& Sossah 2019), so 0.41 was not a different choice of source either.

Three further homologous pairs appear in the same tables and are
deliberately NOT tied. [O I] 6363/6300 = 0.33034 and [Ne III] 3968/3869 =
0.30868 have only their strong component in the catalogue, so there is no
pair to tie. [C I] 9824/9850 = 0.32024 has both components, carried as two
independent lines; tying them would change what the NIR fit is free to do,
which is a separate decision from correcting a ratio already in use.
"""

def doublet_nebular_sum_factor(name):
    """
    The factor taking a fitted doublet weight to the sum over its components.

    A doublet column is built with its components' ratios relative to the
    strong one, and each component profile is area-normalised, so the
    fitted weight is the flux of the ratio-1.0 component alone. Most
    consumers want exactly that -- the BPT diagram is calibrated on
    [O III] 5007 and [N II] 6583, not on doublet sums -- but the [O III]
    temperature diagnostic wants the nebular sum F(4959) + F(5007), and
    multiplying by this factor is what supplies it.

    Derived from the catalogue entry rather than written out again at the
    point of use, because the factor IS one plus the branching ratio. A
    second copy of that number is a second thing to keep in step with the
    design matrix, and the whole point of a branching ratio fixed by
    atomic physics is that there is one of it.

    Dividing by the largest ratio rather than assuming it is 1.0 keeps the
    factor right for a doublet whose ratios were written on some other
    scale.
    """
    ratios = [ratio for _, ratio in TIED_DOUBLETS[name]]
    return sum(ratios) / max(ratios)

def drop_masked_lines(lines, doublets, wavelength, weight, sigma_kms):
    """
    Leave out the lines whose centres the mask (or a gap in the data) covers.

    A line is dropped when fewer than half of the pixels within its rest
    wavelength +- 2 sigma (at `sigma_kms`, and never less than two pixels
    either side) carry weight. Its amplitude is then set by a wing or by
    nothing, and the fit returns an arbitrary flux: a masked H-alpha came
    back at 35 times its true value, and an [N II] 6583 with only its red
    wing outside a mask at 77 times. A few bad pixels on a line do not drop
    it; a masked window or a gap in the spectrum over its core does. A
    doublet loses only the members that are covered; one survivor is fitted
    alone, at ratio 1, under its own name, as for a doublet that loses a
    member to the edge of the grid.

    Parameters
    ----------
    lines : dict
        {name: rest_wavelength}.
    doublets : dict
        {name: [(component, rest_wavelength, ratio), ...]}.
    wavelength : array
        The fitting grid.
    weight : array
        Per-pixel weight on that grid; zero where nothing is fitted.
    sigma_kms : float
        Line width to judge coverage by: the starting gas dispersion.

    Returns
    -------
    lines, doublets : dict
        What is left to fit.
    dropped : list of str
        The names left out.
    """
    lam = np.asarray(wavelength, dtype=np.float64)
    good = np.asarray(weight) > 0
    step = np.median(np.diff(lam)) if lam.size > 1 else 1.0

    def covered(rest):
        half = max(2.0 * float(sigma_kms) / 299792.458 * rest, 2.0 * step)
        inside = (lam >= rest - half) & (lam <= rest + half)
        n = int(np.sum(inside))
        return n > 0 and int(np.sum(good & inside)) < 0.5 * n

    dropped = []
    kept_lines = {}
    for name, rest in lines.items():
        if covered(rest):
            dropped.append(name)
        else:
            kept_lines[name] = rest
    kept_doublets = {}
    for name, members in doublets.items():
        alive = [m for m in members if not covered(m[1])]
        dropped += [m[0] for m in members if m not in alive]
        if len(alive) == len(members):
            kept_doublets[name] = members
        elif len(alive) == 1:
            kept_lines[alive[0][0]] = alive[0][1]
        elif alive:
            kept_doublets[name] = alive
    return kept_lines, kept_doublets, dropped

def get_line_catalog(wavelength_range, wavelength_scale):
    """
    Select the appropriate emission line catalog based on wavelength coverage.

    Parameters
    ----------
    wavelength_range : tuple (wl_min, wl_max)
        Wavelength range of the observed spectrum.
    wavelength_scale : {'air', 'vacuum'}
        The wavelength scale of the OBSERVED spectrum, which is the scale
        the returned rest wavelengths are put on. REQUIRED, with no
        default, at the signature rather than at the call: a default here
        would let a fourth call site be added that silently picks a scale,
        and picking the wrong one shifts every line by about 83 km/s
        without moving chi2 enough to notice. Unknown values raise; see
        line_catalogue.require_scale.

    Returns
    -------
    lines : dict
        {name: rest_wavelength} for single lines.
    doublets : dict
        {name: [(component_name, rest_wavelength, ratio), ...]} for tied
        doublets. The component's catalogue name travels with it because a
        doublet can lose a component to the edge of the grid, and the
        survivor then has to be renamed to say what it actually is. Working
        that out from the wavelength alone would mean matching floats
        against the catalogue, which is the deduplication bug this module's
        docstring describes.

    The margin here is generous on purpose: it decides which lines are
    CANDIDATES, and the question of whether a candidate can land on the
    fitted grid at any velocity the fit is allowed to try is settled later,
    by precompile_line_table, which knows the bounds.
    """
    wl_min, wl_max = wavelength_range
    catalogue = emission_lines_on_scale(wavelength_scale)

    margin = 500.0

    def in_range(w):
        return (wl_min - margin) <= w <= (wl_max + margin)

    lines = {name: w for name, w in catalogue.items() if in_range(w)}

    doublets = {}
    tied_component_names = set()
    for name, components in TIED_DOUBLETS.items():
        resolved = []
        for member, ratio in components:
            if member not in catalogue:
                raise KeyError(
                    f"tied doublet {name!r} names a component {member!r} that "
                    f"is not in the catalogue. Every doublet member must be a "
                    f"catalogue entry, so its wavelength is stored once.")
            resolved.append((member, catalogue[member], ratio))
        if any(in_range(w) for _, w, _ in resolved):
            doublets[name] = resolved
            tied_component_names.update(m for m, _ in components)

    lines_clean = {name: w for name, w in lines.items()
                   if name not in tied_component_names}

    return lines_clean, doublets

def assign_kinematic_groups(lines, doublets, user_groups=None):
    """
    Assign each emission line/doublet to a kinematic group.

    Parameters
    ----------
    lines : dict
        {name: rest_wavelength} from get_line_catalog.
    doublets : dict
        {name: [(component_name, wl, ratio), ...]} from get_line_catalog.
    user_groups : dict or None
        User-defined groups: {group_id: [species, ...]}, matched
        exactly against LINE_SPECIES. If None, uses
        DEFAULT_GROUP_SPECIES.

    Returns
    -------
    line_groups : dict
        {line_name: group_id} for every line and doublet.
    n_groups : int
        Number of distinct kinematic groups.
    """
    wanted = user_groups if user_groups is not None else DEFAULT_GROUP_SPECIES

    by_species = {}
    for gid, species_list in wanted.items():
        for sp in species_list:
            if sp in by_species and by_species[sp] != gid:
                raise ValueError(
                    f"species {sp!r} is listed in kinematic group "
                    f"{by_species[sp]} and again in group {gid}.")
            by_species[sp] = gid

    all_names = list(lines.keys()) + list(doublets.keys())
    line_groups = {}
    for name in all_names:
        sp = species_of(name)
        line_groups[name] = by_species.get(sp, 0) if sp is not None else 0

    n_groups = len(set(line_groups.values())) if line_groups else 1
    return line_groups, n_groups

def build_emission_matrix_grouped(wavelength, velscale, group_kinematics,
                                  lines=None, doublets=None, line_groups=None,
                                  wavelength_scale=None):
    """
    Generate emission line template matrix with per-kinematic-group parameters.

    The profiles come from _build_emission_jit, one kinematic slot per
    column, rather than from a Gaussian written out again here. There used to
    be a second implementation in this function, and a second implementation
    of a line profile is a second thing to keep in step: the compiled path
    had already lost the 8-sigma truncation this one applied, so the two
    paths differed in the far wings before the pixel integration went in and
    would have differed in the core after it.

    Parameters
    ----------
    wavelength : 1D array
        The log-lambda grid, in Angstrom.
    velscale : float
        The grid's step, c * dln(lambda), in km/s per pixel.
    group_kinematics : dict
        {group_id: (sigma_gas, v0_gas)} in km/s.
    lines : dict or None
        Single emission lines {name: rest_wavelength}.
    doublets : dict or None
        Tied doublets {name: [(component_name, wl, ratio), ...]}.
    line_groups : dict or None
        {line_name: group_id}. If None, all lines in group 0.

    Returns
    -------
    M_gas : 2D array (N_pix, N_lines)
        Emission line template matrix, in flux density per Angstrom: each
        column integrates to 1 over wavelength, so a fitted weight is the
        line's total flux. See _build_emission_jit.
    gas_names : list of str
        Names of the emission line columns.
    gas_group_labels : list
        The kinematic group LABEL of each column, as written in line_groups.
        This path looks its kinematics up in the group_kinematics dict by
        label, so it never needs the positional index the compiled path
        gathers with; see precompile_line_table.
    """
    wl = np.asarray(wavelength, dtype=np.float64)
    wl_min, wl_max = float(wl[0]), float(wl[-1])

    if lines is None or doublets is None:
        if wavelength_scale is None:
            raise ValueError(
                "build_emission_matrix_grouped was given neither a line "
                "catalogue nor a wavelength scale to build one on. Pass "
                "lines and doublets from get_line_catalog, or pass "
                "wavelength_scale='air' or 'vacuum' so the catalogue can be "
                "put on the scale of the observed spectrum.")
        lines, doublets = get_line_catalog((wl_min, wl_max), wavelength_scale)

    if line_groups is None:
        line_groups, _ = assign_kinematic_groups(lines, doublets)

    entries = []
    names = []
    group_labels = []
    kinematics = []

    for name, rest_w in lines.items():
        label = line_groups.get(name, 0)
        sig_gas, v0_gas = group_kinematics.get(label, (100.0, 0.0))
        obs_w = rest_w * (1.0 + v0_gas / C_KMS)
        if wl_min <= obs_w <= wl_max:
            entries.append([(rest_w, 1.0)])
            names.append(name)
            group_labels.append(label)
            kinematics.append((sig_gas, v0_gas))

    for name, components in doublets.items():
        label = line_groups.get(name, 0)
        sig_gas, v0_gas = group_kinematics.get(label, (100.0, 0.0))
        kept = [(rest_w, ratio) for _, rest_w, ratio in components
                if wl_min <= rest_w * (1.0 + v0_gas / C_KMS) <= wl_max]
        if kept:
            entries.append(kept)
            names.append(name)
            group_labels.append(label)
            kinematics.append((sig_gas, v0_gas))

    if not entries:
        return np.zeros((len(wl), 0)), [], []

    max_comp = max(len(e) for e in entries)
    rest_wavelengths = np.zeros((len(entries), max_comp))
    ratios = np.zeros((len(entries), max_comp))
    for j, components in enumerate(entries):
        for i, (rest_w, ratio) in enumerate(components):
            rest_wavelengths[j, i] = rest_w
            ratios[j, i] = ratio

    M_gas = _build_emission_jit(
        jnp.asarray(wl), float(velscale),
        jnp.asarray([k[0] for k in kinematics]),
        jnp.asarray([k[1] for k in kinematics]),
        jnp.asarray(rest_wavelengths), jnp.asarray(ratios),
        jnp.asarray([len(e) for e in entries], dtype=jnp.int32),
        jnp.arange(len(entries), dtype=jnp.int32), max_comp,
    )
    return np.asarray(M_gas), names, group_labels

def build_emission_matrix(wavelength, velscale, sigma_gas, v0_gas, lines=None,
                          doublets=None, wavelength_scale=None):
    """
    Legacy wrapper: single kinematic group (backward compatible).
    All lines share the same sigma_gas and v0_gas.

    Parameters
    ----------
    wavelength : 1D array
        The log-lambda grid, in Angstrom. Uniform in ln(lambda): the pixel
        integration the profile carries is defined on that grid and nowhere
        else.
    velscale : float
        The grid's step, c * dln(lambda), in km/s per pixel.
    sigma_gas : float
        Gas velocity dispersion (km/s).
    v0_gas : float
        Gas radial velocity (km/s).
    lines : dict or None
        Single emission lines {name: rest_wavelength}.
        If None, auto-selected from wavelength range.
    doublets : dict or None
        Tied doublets {name: [(component_name, wl, ratio), ...]}.
        If None, auto-selected from wavelength range.
    wavelength_scale : {'air', 'vacuum'} or None
        Needed only when lines and doublets are both None and the catalogue
        has to be built here. Passing a catalogue already settles the scale,
        because its wavelengths are on one.

    Returns
    -------
    M_gas : 2D array (N_pix, N_lines)
        Emission line template matrix.
    gas_names : list of str
        Names of the emission line columns.
    """
    group_kin = {0: (sigma_gas, v0_gas)}
    M_gas, gas_names, _ = build_emission_matrix_grouped(
        wavelength, velscale, group_kin, lines, doublets,
        line_groups=None, wavelength_scale=wavelength_scale
    )
    return M_gas, gas_names

def group_positions(line_groups):
    """
    The position each kinematic group label occupies in the parameter vector.

    A group label is whatever the user wrote in line_groups: any hashable,
    in any order, with any gaps. The fitted parameter vector, in contrast, is
    a flat sequence, and both the scalar optimizer and the cube path lay the
    per-group sigma and v0 out by walking sorted(set(line_groups.values()))
    and appending two slots per group. So the label is a name and the
    position is an index, and the two coincide only for labels that happen
    to be 0, 1, 2, ... in order.

    DEFAULT_GROUP_SPECIES uses 0 and 1, so they did coincide, and
    precompile_line_table shipped the raw label where an index was needed.
    A settings file saying `line_groups: {1: [...], 2: [...]}` then made
    label 2 index a length-2 array; an out-of-bounds gather in JAX is
    clamped rather than raised, so every line in group 2 silently took group
    1's dispersion and velocity and the fit ran to completion.

    Defined here, once, so that the table and the parameter vector are
    derived from the same expression rather than from two that agree by
    inspection.
    """
    return {label: i for i, label in
            enumerate(sorted(set(line_groups.values())))}

def reachable_window(rest_wavelength, v0_gas_bounds, sigma_gas_max):
    """
    The span of observed wavelength a rest wavelength can be moved to.

    A line is shifted by the fitted gas velocity and spread by the fitted
    gas dispersion, and the fit may choose either anywhere inside its
    bounds. So the widest reach is the bluest allowed velocity minus a few
    dispersions, to the reddest allowed velocity plus a few. Three
    dispersions is the same reach brainv1 uses when it restores masked
    pixels around a line, and at three sigma a Gaussian still carries 1.1
    per cent of its peak, which is a contribution a fit can act on.

    Returns (lowest, highest) in Angstrom.
    """
    v_lo = float(v0_gas_bounds[0]) - LINE_REACH_SIGMAS * float(sigma_gas_max)
    v_hi = float(v0_gas_bounds[1]) + LINE_REACH_SIGMAS * float(sigma_gas_max)
    return (rest_wavelength * (1.0 + v_lo / C_KMS),
            rest_wavelength * (1.0 + v_hi / C_KMS))

def precompile_line_table(wavelength, lines, doublets, line_groups,
                          v0_gas_bounds, sigma_gas_max):
    """
    Pre-compute a fixed-shape emission line table for JIT-compatible use.

    Packs single lines (1 component) and doublets (2+ components) into
    padded JAX arrays so _build_emission_jit can run without Python control flow.

    Parameters
    ----------
    wavelength : 1D array
        Wavelength grid.
    lines : dict
        {name: rest_wavelength} single lines.
    doublets : dict
        {name: [(component_name, wl, ratio), ...]} tied doublets.
    line_groups : dict
        {name: group_label} kinematic group assignments.
    v0_gas_bounds : (float, float)
        The gas velocities in km/s the fit is allowed to try.
    sigma_gas_max : float
        The largest gas dispersion in km/s the fit is allowed to try.

    Returns
    -------
    table : dict
        A dictionary with these keys::

            'names'           : list of str (Python, not traced)
            'rest_wavelengths': (n_lines, max_comp) JAX array, 0-padded
            'ratios'          : (n_lines, max_comp) JAX array, 0-padded
            'n_components'    : (n_lines,) int array
            'group_indices'   : (n_lines,) int array, POSITIONS into the fitted
                                per-group sigma and v0 arrays, not labels
            'group_labels'    : list (Python, the labels themselves, for output
                                bookkeeping)

    The two group entries are deliberately different quantities and
    deliberately differently named. 'group_indices' is what the compiled
    kernel gathers with, and it must be a position; 'group_labels' is what
    the user called the group, and it is what a summary should print. See
    group_positions for the failure that followed from conflating them.

    A line whose name is absent from line_groups raises. It used to default
    to group 0, which is a guess: the caller that built lines and doublets
    and the caller that built line_groups had gone out of step, and putting
    the orphan in whichever group happens to sort first hides that.

    WHICH LINES ARE ON THE GRID

    get_line_catalog selects candidates with a fixed 500 A margin, which is
    about coverage and knows nothing about the fit. A candidate that cannot
    reach the grid at any velocity and dispersion inside the bounds used to
    be kept anyway, and it entered the design matrix as a column of exactly
    zero: the non-negative solve went rank-deficient, the weight came back
    0, and the summary reported the line as a non-detection. It was never
    fitted. Saying nothing about a line that was not measured, in the same
    table as lines that were, is the failure this whole module exists to
    stop, so such a line is dropped from the table and named in the log.

    The bounds are arguments rather than a margin invented here, because
    the reach that matters is the one the fit is actually permitted, and
    only the caller knows it. See reachable_window.

    PARTIAL DOUBLETS

    A tied doublet with one component on the grid and one off is kept, as
    the surviving component alone: its ratio is renormalised to 1.0 and the
    entry takes that component's own catalogue name. The alternative --
    keeping the doublet's name and the survivor's branching ratio -- puts a
    column holding one line under a name that every consumer reads as the
    sum of two, so the fitted flux of "[O III]_Doublet" would silently be
    0.33 of one line rather than 1.33 of both. Renaming makes the entry say
    what it is, and gas_diagnostics already resolves a doublet request to
    the components of that species when the doublet name is absent.
    """
    positions = group_positions(line_groups)
    wl_min, wl_max = float(wavelength[0]), float(wavelength[-1])

    def reaches_grid(rest_w):
        lowest, highest = reachable_window(
            rest_w, v0_gas_bounds, sigma_gas_max)
        return highest >= wl_min and lowest <= wl_max

    def resolve_group(name):
        if name not in line_groups:
            raise KeyError(
                f"emission line {name!r} has no kinematic group. Every line "
                f"and doublet handed to precompile_line_table must appear in "
                f"line_groups; assign_kinematic_groups fills one in for every "
                f"name it is given, so this means the catalogue and the group "
                f"assignment were built from different line lists.")
        label = line_groups[name]
        if label not in positions:
            raise ValueError(
                f"emission line {name!r} is in kinematic group {label!r}, "
                f"which is not one of {sorted(positions)}.")
        return label, positions[label]

    entries = []
    off_grid = []

    for name, rest_w in lines.items():
        label, index = resolve_group(name)
        if not reaches_grid(rest_w):
            off_grid.append(f"{name} ({rest_w:.0f} A)")
            continue
        entries.append({
            'name': name,
            'rest_wavelengths': [rest_w],
            'ratios': [1.0],
            'group_label': label,
            'group_index': index,
        })

    for name, components in doublets.items():
        label, index = resolve_group(name)
        kept = [(c, w, r) for c, w, r in components if reaches_grid(w)]
        lost = [(c, w, r) for c, w, r in components if not reaches_grid(w)]

        if not kept:
            off_grid.append(
                f"{name} ({', '.join(f'{w:.0f}' for _, w, _ in components)} A)")
            continue

        entry_name = name
        ratios = [r for _, _, r in kept]
        if lost:
            ratios = [r / max(ratios) for r in ratios]
            if len(kept) == 1:
                entry_name = kept[0][0]
            logger.info(
                f"   {name} loses {', '.join(c for c, _, _ in lost)} to the "
                f"edge of the {wl_min:.0f}-{wl_max:.0f} A grid; the remaining "
                f"{', '.join(c for c, _, _ in kept)} is fitted alone, at "
                f"ratio 1.0, and reported as {entry_name!r}")

        entries.append({
            'name': entry_name,
            'rest_wavelengths': [w for _, w, _ in kept],
            'ratios': ratios,
            'group_label': label,
            'group_index': index,
        })

    if off_grid:
        logger.info(
            f"   {len(off_grid)} emission line(s) cannot reach the "
            f"{wl_min:.0f}-{wl_max:.0f} A grid at any velocity or dispersion "
            f"the fit is allowed, and are NOT fitted or reported: "
            f"{', '.join(off_grid)}")

    if not entries:
        return {
            'names': [],
            'rest_wavelengths': jnp.zeros((0, 1)),
            'ratios': jnp.zeros((0, 1)),
            'n_components': jnp.zeros(0, dtype=jnp.int32),
            'group_indices': jnp.zeros(0, dtype=jnp.int32),
            'group_labels': [],
        }

    max_comp = max(len(e['rest_wavelengths']) for e in entries)

    names, rest_wl, ratio_list, n_comp = [], [], [], []
    indices, labels = [], []
    for e in entries:
        nc = len(e['rest_wavelengths'])
        rw = list(e['rest_wavelengths']) + [0.0] * (max_comp - nc)
        ra = list(e['ratios']) + [0.0] * (max_comp - nc)
        names.append(e['name'])
        rest_wl.append(rw)
        ratio_list.append(ra)
        n_comp.append(nc)
        indices.append(e['group_index'])
        labels.append(e['group_label'])

    return {
        'names': names,
        'rest_wavelengths': jnp.array(rest_wl),
        'ratios': jnp.array(ratio_list),
        'n_components': jnp.array(n_comp, dtype=jnp.int32),
        'group_indices': jnp.array(indices, dtype=jnp.int32),
        'group_labels': list(labels),
    }




@partial(jax.jit, static_argnames=('max_comp',))
def _build_emission_jit(lam, velscale, sigma_gas_arr, v0_gas_arr,
                        rest_wavelengths, ratios, n_components,
                        group_indices, max_comp):
    """
    Build the emission line design matrix, pixel-integrated, JIT-compiled.

    THE CONSTRUCTION

    Each component is built in the Fourier domain, as the analytic transform
    of a Gaussian multiplied by the analytic transform of the one-pixel top
    hat the detector integrates over, and transformed back:

        F_k     = exp(-0.5 (w_k x_sigma)^2 - i w_k x_0) sinc(w_k / 2 pi)
        profile = irfft(F_k, n = N_pix)

    with w_k = 2 pi k / N_pix the angular frequency in radians per pixel,
    x_0 = (ln lambda_obs - ln lambda[0]) / dx the line centre in fractional
    pixels, x_sigma = sigma_total / velscale the width in pixels, and
    dx = velscale / c the log-lambda step. This is Westfall et al. 2019
    (AJ 158, 231) Section 9.1.2, the template equation. sinc(w / 2 pi) is
    sin(w/2) / (w/2), which is exactly the transform of a unit-area one-pixel
    top hat, so the pixel integration is analytic and not a quadrature.

    The sign of the phase is -i because jnp.fft.rfft carries exp(-i w n) in
    its forward kernel. The continuous transform is often written with +i;
    copying that sign here mirrors every line about the first pixel.

    The point of this form is that it is exact at any width, including
    exactly zero: exp(0) = 1, nothing is divided by sigma, and there is no
    guard clamping sigma away from zero. The predecessor sampled a bare
    analytic Gaussian at pixel centres and divided by sqrt(2 pi) sigma_lambda,
    which loses flux as soon as the line is narrower than a pixel -- at
    sigma_gas = 10 km/s on a 58.39 km/s grid it retained 35.7 per cent of the
    line's flux, and the missing 64 per cent is what forced the fitted gas
    dispersion to be floored at one pixel.

    Below about half a pixel the profile shows Fourier ringing, with negative
    side lobes reaching about -12 per cent of the peak at sigma = 0 for an
    unfavourable sub-pixel phase; Westfall's usage notes call this out. The
    ringing is 2.2e-4 of the peak at one pixel of width and 1.9e-5 at 70 km/s,
    so it is irrelevant at any width an instrument with a resolved
    line-spread function can produce, and matters only in the regime that
    removing the floor opens up. Negative entries in a design-matrix column
    are not a problem for the non-negative solve, which constrains the
    weights and not the columns.

    THE NORMALISATION, AND THEREFORE WHAT THE FITTED WEIGHT MEANS

    irfft of the expression above returns a profile that sums to exactly 1.0
    over pixels. That is not the normalisation BRAIN's fitted weights are
    written against. Every consumer of a gas weight -- the summary's flux
    table, the Balmer decrement, the BPT ratios, the Case B penalty rows --
    reads it as the line's total flux in the units of the input spectrum
    times Angstrom. So the profile is divided by lambda_obs * dx, the width
    of one pixel in Angstrom at the line, which converts a per-pixel
    normalisation into a flux density per Angstrom:

        sum_i column_i * dlambda_i = 1

    exactly as the predecessor's 1 / (sqrt(2 pi) sigma_lambda) intended. The
    factor is c / (lambda_obs velscale), about 88 per Angstrom at 5007 A on
    this grid, and it is wavelength-dependent, so it does not cancel between
    lines: omitting it would leave chi2 almost unmoved, because the
    non-negative solve absorbs a per-column constant, and silently rescale
    every reported line flux by a different factor per line.

    Parameters
    ----------
    lam : (N_pix,)
        The log-lambda grid the fit runs on, in Angstrom. Uniform in
        ln(lambda) by construction; the pixel index x_0 is only meaningful
        on such a grid.
    velscale : float
        The grid's step, c * dln(lambda), in km/s per pixel.
    sigma_gas_arr : (n_groups,) dispersion per kinematic group, km/s
    v0_gas_arr : (n_groups,) velocity per kinematic group, km/s
    rest_wavelengths : (n_lines, max_comp) — 0-padded
    ratios : (n_lines, max_comp) — 0-padded
    n_components : (n_lines,) — unused at runtime (padding handles it)
    group_indices : (n_lines,) — POSITION of each line's kinematic group in
        sigma_gas_arr and v0_gas_arr. Not the group's label. An out-of-range
        gather is clamped by JAX, not raised, so a label used here in place
        of a position gives every affected line another group's kinematics
        and no error at all; precompile_line_table is where the conversion
        happens, and group_positions says why.
    max_comp : int (static)
        Carried for the caller's bookkeeping; the padded columns are killed
        by their zero ratio rather than by a loop bound.

    Returns
    -------
    M_gas : (N_pix, n_lines)

    A padded component has rest wavelength 0, and ln(0) is not a number, so
    the padding is given the grid's first wavelength before the logarithm is
    taken and killed afterwards by its zero ratio. Multiplying a NaN by zero
    does not kill it.

    The transform length is N_pix itself rather than a padded power of two.
    Padding reproduces the profile a power-of-two transform gives to 2e-16
    but leaves the sum at 1.0000113 instead of 1; at N_pix the sum is exactly
    1.0 and the profile differs from the padded one by at most 8.5e-5 at
    sigma = 10 km/s and 1.6e-15 at 150 km/s. Flux conservation and a static
    shape are worth more here than agreement with any particular padding.

    With no lines n_lines is a shape and therefore static, so the empty case
    is a branch taken at trace time. fast_engine never reaches here with no
    lines because it guards on S.fit_lines; the cube path has no such wrapper
    and asks for the empty matrix directly.
    """
    n_pix = lam.shape[0]
    n_lines = rest_wavelengths.shape[0]

    if n_lines == 0:
        return jnp.zeros((n_pix, 0))

    dx = velscale / C_KMS
    omega = 2.0 * jnp.pi * jnp.arange(n_pix // 2 + 1) / n_pix
    pixel_top_hat = jnp.sinc(omega / (2.0 * jnp.pi))

    sigma_gas = sigma_gas_arr[group_indices][:, jnp.newaxis]
    v0_gas = v0_gas_arr[group_indices][:, jnp.newaxis]

    present = rest_wavelengths > 0.0
    obs_w = jnp.where(present,
                      rest_wavelengths * (1.0 + v0_gas / C_KMS),
                      lam[0])

    sigma_total = jnp.broadcast_to(sigma_gas, obs_w.shape)

    x_0 = (jnp.log(obs_w) - jnp.log(lam[0])) / dx
    x_sigma = sigma_total / velscale

    transform = (jnp.exp(-0.5 * (omega * x_sigma[..., jnp.newaxis]) ** 2
                         - 1j * omega * x_0[..., jnp.newaxis])
                 * pixel_top_hat)
    profile = jnp.fft.irfft(transform, n=n_pix, axis=-1)

    density = profile / (obs_w * dx)[..., jnp.newaxis]
    M_gas_T = jnp.sum(ratios[..., jnp.newaxis] * density, axis=1)
    return M_gas_T.T
