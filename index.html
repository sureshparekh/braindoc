BRAIN Spectral Fitting

Start fitting
with BRAIN

From one spectrum to a whole IFU datacube: stellar populations, dust, kinematics, emission lines and the nebular continuum, fitted together, with an uncertainty on every number. Built on JAX, it runs on a laptop CPU and scales across GPUs.

Install First fit in the interface First fit in Python API reference Tutorial scripts 
import brainsp

r = brainsp.fit_spectrum("galaxy.spec",
                         nebular_mode="espop",
                         wavelength_scale="vacuum")
print(r.av, r.av_err, r.sigma_star, r.mean_log_age_light)

cube = brainsp.fit_cube("manga.fits", redshift=0.0242,
                        wavelength_scale="vacuum",
                        sn_mask=[3], fit_sn_threshold=3)
velocity = cube.plane("vrot_star")
brainsp.plots.map(cube, "vrot_star", "velocity.pdf")

Choose how you work

The interface, the Python library and the command line drive the same engine with the same settings, so a spectrum gives the same numbers whichever you use. A run set up in the interface can be saved as a Python file, and anything fitted in Python opens in the interface.

Measured speed

On one workstation, with BRAIN sizing itself as it does by default: an NVIDIA GeForce RTX 3060 (12 GB, a consumer card) with 64 GPU lanes, or an AMD Ryzen Threadripper 2990WX (32 cores, 64 threads) with 32 worker processes.

The JWST cube: a galaxy observed with the NIRSpec IFU, 39 × 43 spaxels, fitted from 1.57 to 2.35 µm in every spaxel above S/N 5. The model: spop with the M13 library, 47 simple stellar populations of Maraston (2013) plus 3 power laws and 7 hot-dust blackbodies for an AGN, CCM dust and one 2σ clip-and-refit pass. All 1274 spaxels converged, and the CPU and GPU fits agree. Per spaxel is the fit itself; start to finish adds reading the cube, compiling and writing the megacube. The single spectrum is a mock with emission lines. CPUs and GPUs gives every measurement.
