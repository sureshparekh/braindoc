Reading a megacube#

A datacube’s fit is one FITS file, the megacube. brainsp.read_megacube() opens it as a Megacube, which names and groups every map it holds and reads any spaxel’s spectrum and population.

import brainsp

cube = brainsp.read_megacube("brain_ifu_out/mock_cube-BRAIN_MEGACUBE.fits")
cube.shape                         # (16, 16)
cube.groups.keys()                 # the groups of maps
age = cube.plane("Mage_L")         # a 2-D array, NaN where nothing was fitted
age_err = cube.plane("Mage_L error")

The maps#

cube.names() lists every map the file can give, and cube.groups holds them by group:

Group

Maps, for example

"Populations"

xyy_light … xo_mass (light and mass in each age bin), Av, YAV, Mage_L, Mage_M, MZ_L, MZ_M, F_Norm, Dsigma_inst, LSF_flag

"Kinematics"

Sigma_star (observed), Sigma_star_c (intrinsic), vrot_star, and Sigma_gas_g0, vrot_gas_g0, … for each gas group

"Fit quality"

Adev, ChiSqrt, SNR, Nl_eff, Niter, BadSpaxel, chi2 reduced, status

"Emission lines"

"<line>  flux", "<line>  EW", "<line>  velocity", "<line>  sigma"

"Diagnostics"

"BPT [N II]", "BPT [S II]", "WHAN": class maps

"Nebular"

AV_neb, AV_src, MODE, y_neb, logQH, tau_Hb, Hb_pred, Hb_obs, HaHb, Te, ne, cond_src (nespop)

"Line-spread function"

"LSF sigma_star", "LSF delta_sigma_inst", "LSF flag"

"Uncertainties"

"<map> error", the 1σ error of every map that has one (only maps with at least one error written are listed)

cube.plane(name) returns any of them as an (n_y, n_x) array, with NaN where no spaxel was fitted. An error map is NaN where BRAIN withheld the error (Uncertainties).

import numpy as np
v = cube.plane("vrot_star")
v_err = cube.plane("vrot_star error")
good = np.isfinite(v_err) & (v_err < 10)        # spaxels with v* known to 10 km/s

One spaxel#

obs, model, lines = cube.spectrum(8, 12)       # on cube.wave
cube.populations(8, 12)                         # light (and mass) fractions, in cube.ages order
cube.numbers(8, 12)                             # every PoPBins value at the spaxel, by name

Method

Returns

spectrum(y, x)

the observed and model spectra on cube.wave, and each fitted line’s Gaussian profile as (name, array)

populations(y, x)

the population vector: light fractions, and mass fractions where the file has them, in the order of cube.ages

numbers(y, x)

{name: value} for every PoPBins map at that spaxel

line_flux(name)

one line’s flux map, from FLUX_M

diagnostic_inputs()

the maps of log [N II]/H\(\alpha\), log [O III]/H\(\beta\), log [S II]/H\(\alpha\) and EW(H\(\alpha\))

close()

closes the file

The array index is [y, x], row first, with the origin at the lower left as the maps are drawn.

Attributes#

Attribute

Meaning

path

the file

shape

(n_y, n_x)

wave

rest-frame wavelengths of FLXOBS and FLXSYN, Å

lines

the emission lines fitted (empty in spop)

ages

every template’s age, yr

status

1 where a spaxel was fitted, 0 where it was not

groups, maps

the maps by group, and the extension and plane each is read from

h

the open FITS file itself (an astropy.io.fits.HDUList), for anything else

The diagnostic classes#

brainsp.megacube also exposes the curves and classifiers the maps use, for your own line ratios:

Function

What it is

kewley01(x)

the Kewley et al. (2001) maximum-starburst curve in the [N II] diagram

kauffmann03(x)

the Kauffmann et al. (2003) pure star-formation curve

cid10(x)

the Cid Fernandes et al. (2010) LINER/Seyfert line

bpt_nii_class(n2ha, o3hb)

the [N II] BPT class of log ratios: star forming, composite, LINER or Seyfert

bpt_sii_class(s2ha, o3hb)

the [S II] BPT class (Kewley et al. 2006)

whan_class(n2ha, ew_ha)

the WHAN class (Cid Fernandes et al. 2011)

The raw file#

Everything is also in the FITS file itself, for any program: Megacube files describes every extension and plane.
