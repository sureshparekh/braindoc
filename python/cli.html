The command line#

The brainsp command (also python -m brainsp) does what the library does, from a terminal and without a display: on a laptop, a server or a cluster node. Each task is a sub-command; brainsp COMMAND --help describes one, and Command line prints every command’s own help.

Command

What it does

brainsp gui

open the desktop interface

brainsp fit SPECTRA...

fit one or more spectra

brainsp cube CUBES...

fit datacubes, with their pre-fitting stages

brainsp selftest [--quick]

check the installation

brainsp examples [FOLDER]

write the mock spectra and datacube

brainsp init FILE

write a run as a Python file (run.py) or the documented settings file (settings.yaml)

brainsp check [SETTINGS]

validate settings, fit nothing

brainsp settings [NAME]

describe one setting, or all

brainsp libraries [info NAME | install FOLDER]

list, describe or install template libraries

brainsp plot RESULT

draw a figure from a result or a megacube

brainsp desktop [--remove]

add BRAIN to the applications menu, or remove it

brainsp clear-cache

forget the compiled code and the cached templates

brainsp version

print the version

Settings on the command line#

fit, cube and check take the settings in two ways, which combine:

brainsp fit galaxy.spec --settings my_settings.yaml          # a settings file
brainsp fit galaxy.spec --set nebular_mode=espop \
                        --set wavelength_scale=vacuum \
                        --set "dust_range=[-1, 3]"           # any setting by name

--set NAME=VALUE may be repeated; the value is read as YAML, so numbers, lists and true/false need no special quoting beyond what the shell needs. A --set overrides the same setting in --settings.

brainsp fit#

brainsp fit spectra/*.spec -o results --corrections spectra/corrections.csv --device gpu

Option

Meaning

SPECTRA

files or glob patterns; with none, the spectrum setting is used

-o, --output

the output folder (brain_out)

--corrections

a CSV of per-spectrum corrections: file name, then any of redshift, ebv, rv, law, rest_frame (Corrections before the fit)

--settings, --set

the settings

--device

auto, cpu or gpu

-q, --quiet

only warnings

brainsp cube#

brainsp cube manga.fits --redshift 0.0242 --wavelength-scale vacuum \
    --sn 3 10 --fit-sn 3 --set nebular_mode=espop -o megacubes

Option

Meaning

CUBES

FITS cubes, or none with --table

--redshift

the galaxy’s redshift (required unless --table gives one per cube)

-o, --output

the output folder (brain_ifu_out)

--flux-hdu, --error-hdu, --error-type, --mask-hdu

the extensions, and what the uncertainty is (inv_variance, variance, error, inv_error); --mask-hdu none for no mask

--wavelength-scale

air or vacuum

--ebv, --rv, --law

Galactic dereddening

--bin N

spatial binning, N × N spaxels

--spectral-bin STEP

a uniform wavelength step, in Å

--degrade "TYPE VALUE TYPE VALUE"

degrade the resolution, e.g. "R 2200 R 1000" or "FWHM 2.5 FWHM 6"

--butterworth ["ORDER RANGE"]

the spatial low-pass filter, with its defaults or e.g. "3 0.3"

--sn T...

S/N thresholds to make masks for

--fit-sn T

fit only the spaxels above this threshold

--mask FILE

a wavelength mask for every spaxel

--table FILE

a CSV of per-cube values (Many datacubes)

--no-fit

run the pre-fitting stages only

--gpu-slots N

fits at once on the GPUs (auto)

--batch-size N

fix the number of spaxels in flight

--check

validate only

--export FILE.py

write the run as a Python file instead of running it

--settings, --set, --device

as for fit

brainsp plot#

brainsp plot brain_out/galaxy_summary.txt -o fit.png                  # a spectrum's fit
brainsp plot brain_out/galaxy_summary.txt --sfh -o sfh.png            # its star formation history
brainsp plot galaxy-BRAIN_MEGACUBE.fits                                                # list a megacube's maps
brainsp plot galaxy-BRAIN_MEGACUBE.fits --map vrot_star Mage_L -o maps.pdf --cmap RdBu_r
brainsp plot galaxy-BRAIN_MEGACUBE.fits --spaxel 20,21 --xlim 6450,6650 -o spaxel.png
brainsp plot galaxy-BRAIN_MEGACUBE.fits --diagnostic "BPT [N II]" -o bpt.png
brainsp plot galaxy-BRAIN_MEGACUBE.fits --export maps --formats png,pdf,fits

brainsp init, check, settings#

brainsp init settings.yaml                     # every setting, with its documentation
brainsp init run.py spectra/*.spec             # a spectrum run as one Python file
brainsp init run_cube.py cube.fits --kind cube # a datacube run
brainsp check settings.yaml                    # every problem at once, fit nothing
brainsp check settings.yaml --cube             # ... for a datacube fit
brainsp settings dust_range                    # what one setting does

brainsp libraries#

brainsp libraries                              # list them
brainsp libraries info M13                     # what one holds
brainsp libraries install /data/MILES_SSP --overwrite

Exit status#

Every command exits with 0 on success and non-zero otherwise (cube when a cube was not written, selftest when a check failed), so it can stop a shell script or a pipeline.
