Fitting a datacube#

A datacube is fitted by a CubePipeline: the cube or cubes, the stages to run before the fit, the masks, and the fit itself, written as one megacube per cube. fit_cube() is the same in one call for a single cube.

In one call#

import brainsp

cube = brainsp.fit_cube("manga-8626-12704-LOGCUBE.fits", redshift=0.0242,
                        settings=brainsp.Settings(nebular_mode="espop"),
                        wavelength_scale="vacuum",
                        sn_mask=[3, 10], fit_sn_threshold=3,
                        output_dir="megacubes")
cube.plane("Mage_L")          # the light-weighted mean age map

brainsp.fit_cube(cube, redshift, settings=None, *, device=None, gpu_slots="auto",
                 **options)

options are any keyword of CubePipeline below; the result is the megacube, opened as a Megacube.

The pipeline#

p = brainsp.CubePipeline(
    ["galaxy_a.fits", "galaxy_b.fits"], redshift=0.0242,
    settings="my_settings.yaml",
    wavelength_scale="vacuum",
    sn_mask={"thresholds": [3, 10], "sn window": [5650, 5750]},
    fit_sn_threshold=3,
    output_dir="megacubes")
p.validate()                  # check everything, fit nothing
written = p.run()             # the megacubes written, a list of paths

Meaning

None

{"input type": "R", "input value": 2200, "output type": "R", "output value": 1000}; types "R", "FWHM" or "sigma" (Å)

Pre-fitting stages describes each stage, and what it does to the noise.

Which spaxels and wavelengths#

Keyword

Default

Meaning

sn_mask

None

S/N thresholds to compute masks for, [3, 10], or a dictionary with "thresholds", "sn window" (rest frame, Å) and "method"

fit_sn_threshold

None

fit only the spaxels above this threshold, one of sn_mask’s; every spaxel when None

wavelength_mask

None

a mask file, or regions [(start, end, weight), ...], applied to every spaxel

The S/N method is how a spaxel’s S/N is measured over the window:

Method

Formula

For an uncertainty that is

"ivar" (default)

mean of flux × √ivar

an inverse variance

"ivar_median"

median of flux × √ivar

an inverse variance

"variance"

mean of flux / √var

a variance

"error"

mean of flux / error

an error

"mean_std"

mean(flux) / std(flux)

anything (reads no uncertainty)

Its methods#

Method

What it does

p.run(device=None, progress=None, log=None, gpu_slots="auto")

runs every cube and returns the megacubes written; progress(fraction, message) and log(line) receive the run’s progress, gpu_slots spreads the work over GPUs (Many datacubes)

p.validate()

checks the whole run without fitting, raising an error that lists every problem

p.export_script(path, device="auto")

writes the run as one Python file (A run as one file)

p.config()

the run as the dictionary BRAIN’s datacube runner reads

CubePipeline.from_config(cfg, settings=None)

the reverse: a pipeline from such a dictionary or a saved file

What a run does#

For each cube, in turn: it opens the file, runs the enabled pre-fitting stages in their order, computes the S/N masks, fits the selected spaxels and writes the megacube under a temporary name, then moves it into place, so a stopped run never leaves a truncated file under a finished result’s name. The fit itself has the same stages as a single spectrum’s (stellar kinematics alone, the joint fit, the masked population fit, the lines, the nebular fit in nespop, the uncertainties), on every spaxel independently; The model describes them.

Reading the result#

cube = brainsp.read_megacube(written[0])

Reading a megacube describes everything a Megacube gives, and Megacube files every extension of the file.
