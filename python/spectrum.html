PythonSpectra

Fitting one spectrum#

brainsp.fit_spectrum() fits one spectrum, writes its files and returns a FitResult.

import brainsp

r = brainsp.fit_spectrum("galaxy.spec", nebular_mode="espop",
                         wavelength_scale="vacuum", output_dir="results")
print(r)
print(r.av, r.av_err, r.sigma, r.mean_log_age_light)

The call#

brainsp.fit_spectrum(spectrum, settings=None, *, output_dir=None, device=None,
                     name=None, quiet=False, **overrides)

Parameter

Meaning

spectrum

a spectrum file, or a tuple (wavelength, flux), (wavelength, flux, error) or (wavelength, flux, error, flag) of arrays

settings

a Settings, a dictionary or a YAML file; BRAIN’s defaults when omitted

output_dir

where the files go; the setting output_folder (brain_out) by default, relative to the working directory

device

"auto", "cpu" or "gpu"; only the first fit of a Python session can choose (CPUs and GPUs)

name

the base name of the output files; the spectrum file’s name by default, required for arrays

quiet

show only warnings, not the progress log

**overrides

any setting by name, overriding settings

It returns a FitResult, and writes <name>_summary.txt, <name>_fitted.txt, <name>_settings.txt and, unless make_plot=False, <name>_fit.pdf (What a fit writes).

From arrays#

import numpy as np
w, f, e = np.loadtxt("galaxy.txt", unpack=True, usecols=(0, 1, 2))
r = brainsp.fit_spectrum((w, f, e), name="galaxy", output_dir="results")

Arrays are first written to the output folder as a spectrum file, so that the result, like every result, names a file it can be read back from.

What happens, in order#

  1. The spectrum is read and its pixels without a valid error or with a non-zero flag are set aside (Your data).

  2. The corrections are applied (Corrections before the fit): the Milky Way’s reddening is removed at the observed wavelengths, then the redshift if the spectrum is in the observed frame.

  3. The range is cut to wavelength_min–wavelength_max.

  4. The fit runs, as a datacube of one spaxel: the same native-pixel fitter every spaxel of a cube goes through, with the same stellar kinematics, line catalogue, nebular treatment and uncertainties. A spectrum and a spaxel holding it cannot disagree.

  5. The files are written and read back into the FitResult.

When it stops#

fit_spectrum raises an error, and writes nothing, when the fit cannot be trusted to mean what it would say: a wavelength scale missing in a line mode, a library that cannot run the mode asked for, a fitting range outside the data, no pixel left to fit. Each message names the setting to change. A fit that runs but ends badly (a parameter on its bound, a poor \(\chi^2\)) is written, with warnings in the log and in the summary (Troubleshooting).
