Template libraries#

A template library is a folder of simple stellar population (SSP) spectra, with a CATALOGUE.txt that lists them. BRAIN fits a galaxy as a non-negative mixture of the library’s templates, so the library decides what a fit can say: its ages, its metallicities, its wavelength range and resolution, and whether it reaches the ionising ultraviolet.

BC03 holds the same files FADO’s Base.BC03.L lists. Two of them, the 1 and 2.09 Myr templates at Z = 0.004, have identical spectra in that release, so the fit’s split of light between the pair is arbitrary; their sum is not. Its files do not state their resolution, so with instrumental_resolution set, also give library_resolution for an intrinsic \(\sigma_\star\) (Emission lines and resolution).

Choose a library and its templates#

r = brainsp.fit_spectrum("galaxy.spec", base_folder="M13",
                         ages=[1e7, 1e8, 1e9, 5e9, 1.26e10],
                         metallicities=[0.01, 0.02])

Setting

Meaning

base_folder

the library, by name or by folder path

ages

ages in years, or "all" (default)

metallicities

metallicities as mass fractions, or "all" (default)

include_power_law

add the library’s AGN set (its own, or the package’s seven)

An age or metallicity not in the catalogue is an error, and BRAIN names the nearest ones it has. A shorter list of ages fits faster and is less degenerate, at the cost of a coarser star formation history; spread the ages out rather than clustering them.

Inspect one#

from brainsp import libraries

libraries.available()             # ['BasesGM', 'M13'], and any you add
info = libraries.info("M13")
info["n_ssp"], info["wavelength_min"], info["wavelength_max"], info["reaches_lyman"]
info["ages_yr"], info["metallicities"]
libraries.nebular_status("M13")   # can it run nespop?

On the command line: brainsp libraries lists them, brainsp libraries info M13 describes one.

Add one#

libraries.install("/data/MILES_SSP")             # copied to ~/.brainsp/libraries/MILES_SSP
libraries.install("/data/my_ssps", name="MY_SSPS")
r = brainsp.fit_spectrum("galaxy.spec", base_folder="MILES_SSP")

install() checks that the folder is a library and that every file its catalogue names exists, then copies it to the per-user library folder, ~/.brainsp/libraries (or $BRAINSP_HOME/libraries), where it can be named like a shipped one. To use a library where it is, without copying, put its parent folder on the BRAINSP_LIBRARY_PATH environment variable. A library is found, by name, in this order: a path given directly; each folder of BRAINSP_LIBRARY_PATH; the per-user folder; the package’s own.

The catalogue#

# AGE_YR      Z         FILENAME                 SHORT_NAME   MSTARS   KIND
1.0e+06       0.019     bc03_z019_t1e6.dat       t1e6_z019    1.0      ssp

Column

Meaning

AGE_YR

age, years

Z

metallicity, mass fraction

FILENAME

the template file, in the library folder

SHORT_NAME

the name used in outputs

MSTARS

the fraction of the initial mass still in stars and remnants at that age; turns light fractions into masses

KIND

ssp for a stellar population, powerlaw (or blackbody) for a featureless component that carries light but no mass

Each template file holds two columns: wavelength in Å (rest frame) and flux per unit wavelength. A library may carry its own AGN set in an AGN sub-folder with a catalogue of the same layout; include_power_law then adds that set instead of the package’s seven.

Resolution#

The templates’ resolution matters for every dispersion BRAIN reports. BRAIN reads it from the template files’ headers where they state it; otherwise give it as library_resolution (a FWHM in Å, or "45 km/s" as a constant velocity dispersion). Without it, \(\sigma_\star\) is reported as an observed dispersion only (Emission lines and resolution).
