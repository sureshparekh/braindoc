PythonResults

Figures#

brainsp.plots draws every figure the interface shows, from a FitResult, a Megacube or the path of either. Every function returns the Matplotlib figure, and writes it to a file when given a path (.png, .pdf or .svg).

Function

Draws

spectrum()

a spectrum and its model, with the stellar and line components and the residuals

spectrum_fit()

the standard figure a fit writes with make_plot

sfh()

the star formation history, in light and in mass

map()

one map of a megacube

maps()

several maps on one page

spaxel()

one spaxel’s spectrum, model and lines

diagnostic()

a BPT or WHAN diagram, every spaxel coloured by class

export_maps()

maps as image and FITS files

A spectrum#

import brainsp
r = brainsp.read_result("brain_out/galaxy_summary.txt")

brainsp.plots.spectrum(r, "fit.png")                        # the whole fit
brainsp.plots.spectrum(r, "halpha.png", xlim=(6450, 6650))  # zoom on H-alpha and [N II]
brainsp.plots.sfh(r, "sfh.png")                             # light and mass against age
brainsp.plots.sfh(r, "cumulative.png", kind="mass", cumulative=True)

spectrum(result, path=None, *, ax=None, xlim=None, components=True, residuals=True, title=None) draws the data, the model, its stellar and line parts (components) and a residual panel (residuals). sfh(source, path=None, *, y=None, x=None, kind="both", ax=None, cumulative=False) sums the fractions at each age over metallicity; kind is "light", "mass" or "both", and cumulative=True shows the fraction formed, oldest first.

A datacube#

cube = brainsp.read_megacube("brain_ifu_out/galaxy-BRAIN_MEGACUBE.fits")

brainsp.plots.map(cube, "vrot_star", "velocity.pdf", cmap="RdBu_r")
brainsp.plots.map(cube, "Halpha_6563  flux", "ha.png", scale="log")
brainsp.plots.maps(cube, ["Mage_L", "MZ_L", "Av", "Sigma_star"], "page.pdf", ncols=2)
brainsp.plots.spaxel(cube, 20, 21, "spaxel.png", xlim=(4800, 5050))
brainsp.plots.sfh(cube, "sfh_centre.png", y=20, x=21)
brainsp.plots.diagnostic(cube, "BPT [N II]", "bpt.png")

map(cube, name, path=None, *, ax=None, cmap="viridis", scale="clip", vmin=None, vmax=None, contours=False, title=None, units=None):

Keyword

Effect

cmap

any Matplotlib colour map; "RdBu_r" suits velocities

scale

"clip" (linear, 1st to 99th percentile), "full" (linear, full range) or "log"

vmin, vmax

fixed limits, overriding scale

contours

overlay the map’s own contours

diagnostic(cube, kind="BPT [N II]", ...) takes "BPT [N II]", "BPT [S II]" or "WHAN".

Into your own figure#

Every function that draws one panel takes ax=, and then draws into those axes instead of making a figure:

import matplotlib.pyplot as plt
fig, (a, b) = plt.subplots(1, 2, figsize=(10, 4))
brainsp.plots.map(cube, "Mage_L", ax=a)
brainsp.plots.diagnostic(cube, "WHAN", ax=b)
fig.savefig("panel.pdf")

Export maps as files#

brainsp.plots.export_maps(cube, "maps", names=["Mage_L", "Av", "vrot_star"],
                          formats=("png", "pdf", "fits"))

One file per map and format. The FITS files carry the cube’s sky coordinates and a TRUST extension whose bits say why a spaxel is not a measurement (not fitted, no value), so each can be read without the megacube. Without names, every map is written. From the command line: brainsp plot MEGACUBE --export maps --formats png,pdf,fits.
