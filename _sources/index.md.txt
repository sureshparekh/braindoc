# BRAIN

**Stellar population synthesis by full spectral fitting, for spectra and IFU
datacubes, on a CPU or a GPU.**

BRAIN takes a galaxy spectrum, or every spaxel of an integral-field
datacube, and finds the mixture of stellar populations that produced it:
their ages and metallicities, the dust in front of them and the motion of
the stars. It can fit the ionised gas at the same time (emission lines and,
with a library that reaches the ionising ultraviolet, the nebular
continuum) and a featureless AGN continuum. It is written in
[JAX](https://jax.readthedocs.io), so the same code runs on a laptop CPU or a
datacentre GPU.

The Python package is called **`brainsp`** (the name `brain` was taken).

```python
import brainsp

r = brainsp.fit_spectrum("galaxy.spec")                 # one spectrum
print(r.v0, r.sigma, r.av, r.mean_log_age_light)
brainsp.plots.spectrum(r, "fit.png")

cube = brainsp.fit_cube("cube.fits", redshift=0.02)     # a datacube
brainsp.plots.map(cube, "vrot_star", "velocity.png")
```
